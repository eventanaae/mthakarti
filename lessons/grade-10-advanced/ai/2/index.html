Layers of a Neural Network (طبقات الشبكة العصبية)

🤖 الذكاء الاصطناعي والتكنولوجيا🎓 الصف العاشر متقدم📌 هيكل الامتحان: L01 Neural Networks and Deep Learning

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

Simple model: INPUT → HIDDEN LAYER(S) → OUTPUT

LayerDefinitionExample
Input layer (طبقة الإدخال)The first layer, where data enters the systemA photo of a cat uploaded for identification
Hidden layer (الطبقة المخفية)The middle layers where data is processed and patterns are foundDetecting edges, shapes and textures in an image
Output layer (طبقة الإخراج)The final layer that produces the result or predictionThe system giving the final answer: "this is a cat"
How to count hidden layers: a hidden layer is any layer of neurons located between the input layer and the output layer. Count the columns of neurons, not the individual neurons.
A: Input → Hidden → Output = 1 hidden layer
B: Input → Hidden → Hidden → Output = 2 hidden layers
C: Input → Hidden → Hidden → Hidden → Hidden → Output = 4 hidden layers
Self-driving car: the cameras/sensors collect information first → this is the input. The decision (e.g. stop for the pedestrian) comes from the output.
⚠️ Do not count the input and output layers as hidden layers.

اختبر نفسك: أسئلة على Layers of a Neural Network (طبقات الشبكة العصبية)

Which layer produces the final prediction?

✅ الجواب: Output layer

The output layer gives the result or prediction.

Which order is correct?

✅ الجواب: Input → Hidden layer → Output

Data enters, is processed in hidden layers, then a prediction is output.

Where are patterns found and data processed?

✅ الجواب: In the hidden layers

Hidden layers process data and find patterns.

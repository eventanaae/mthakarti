Grammar: Question Tags

🌦️ English🎓 الصف العاشر متقدم📌 هيكل الامتحان: Part 2 Grammar - G.17.3 Questions (question tags)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

A question tag is a short question added to a statement to check information or ask for agreement.

Rule: positive statement → negative tag; negative statement → positive tag. The tag repeats the auxiliary (or modal) and uses a pronoun.

Special cases: I am → aren't I? | Let's → shall we? | Imperative (Close the door) → will you? | Nobody / nothing / never (negative meaning) → positive tag: Nobody was hurt, were they? | There is → isn't there?

"The witness saw the crash, didn't she?"
⚠️ Do not use a noun in the tag ("The man is..., isn't the man?" ✗). Use he/she/it/they/there. And match the tense: He has gone, hasn't he? (not "doesn't he").

The idea in detail

A question tag is a short question added at the end of a statement. We use it to check information ("You have a prescription, don't you?") or to ask for agreement ("It's a good report, isn't it?"). The voice usually goes up when we are really asking, and down when we expect agreement.

The rules, step by step

  1. Positive statement → negative tag; negative statement → positive tag.
  2. The tag uses the same auxiliary or modal as the statement: is, are, was, has, have, can, will, must...
  3. If there is no auxiliary (simple present or simple past), use do / does / did.
  4. The tag uses a pronoun (he, she, it, they, we, you, I, there), never a noun.
  5. Use the contracted negative: isn't, don't, hasn't, can't.

Special cases

  • I am → aren't I? ("I'm late, aren't I?")
  • Let's → shall we?
  • Commands (imperatives) → will you? ("Close the door, will you?")
  • Negative words nobody, nothing, never, hardly make the statement negative → positive tag: "Nobody was hurt, were they?"
  • There is / There are → "There is a doctor here, isn't there?"
Example 1. "The witnesses saw the crash, ____?" Past simple, positive, plural → didn't they.
Example 2. "Nobody has been injured, ____?" "Nobody" = negative meaning → positive tag; the auxiliary is has, and the pronoun used for nobody is they, which takes have → have they.
Example 3. "You haven't finished the report, ____?" Negative → positive → have you.
Example 4. "Let's check the facts, ____?" → shall we.
⚠️ Common mistakes: (1) Using a noun: "The man is here, isn't the man?" ✗ → "isn't he?" ✓. (2) Keeping the same polarity: "She is late, is she?" is possible only in special cases (showing surprise); in tests use the opposite. (3) Wrong auxiliary: "He has gone, doesn't he?" ✗ → "hasn't he?". (4) Forgetting the negative words (never, nobody) in the statement. (5) Writing the tag without a question mark.
Exam corner: G.17.3 Questions (question tags), Part 2. Method: find the first auxiliary (or decide on do/does/did), reverse the polarity, choose the correct pronoun, and check the tense. Most options will look similar (isn't it / doesn't it / wasn't it), so check the tense of the statement first.

Quick summary

  • Positive → negative tag; negative → positive tag.
  • Repeat the auxiliary; use do/does/did if none.
  • Tag = auxiliary + pronoun.
  • Special: aren't I, shall we (let's), will you (commands).

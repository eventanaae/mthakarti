تحليل ثلاثية الحدود <span class="m">x² + bx + c</span>

🧮 الرياضيات🎓 الصف العاشر متقدم📌 هيكل الامتحان: Q4 · ص 671 · أمثلة 1-6

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
لتحليل x² + bx + c ابحث عن عددين m و n بحيث:
m × n = c (حاصل الضرب = الحد الثابت) و m + n = b (المجموع = معامل x).
فيكون التحليل (x + m)(x + n).

x² + 7x + 12: حاصل الضرب 12 والمجموع 7 ← 3 و 4 ← (x + 3)(x + 4)
x² − 5x + 6: ضرب 6 ومجموع −5 ← −2 و −3 ← (x − 2)(x − 3)
x² + 2x − 15: ضرب −15 ومجموع 2 ← 5 و −3 ← (x + 5)(x − 3)
x² − x − 20: ضرب −20 ومجموع −1 ← −5 و 4 ← (x − 5)(x + 4)
x² − 9x + 20 = (x − 4)(x − 5)
⚠️ تحقق دائماً بـ FOIL. وانتبه لإشارة المجموع: للعددين −5 و 2 مجموعهما −3 (وليس 3).

الفكرة بالتفصيل

ثلاثية الحدود على الصورة x² + bx + c (معامل x² يساوي 1) تنتج من ضرب ذوي الحدين (x + m)(x + n). عند تطبيق FOIL تحصل على x² + (m + n)x + mn. بالمقارنة مع x² + bx + c يجب أن يكون m + n = b وm · n = c. إذن التحليل يعني إيجاد عددين حاصل ضربهما c ومجموعهما b.

طريقة موثوقة: اكتب أزواج عوامل c، وابحث عن الزوج الذي مجموعه b، ثم اكتب (x + m)(x + n).

حاصل الضرب يخبرك هل الإشارتان متشابهتان (c موجب) أم مختلفتان (c سالب). والمجموع يخبرك أي إشارة "تغلب".

أمثلة محلولة

مثال 1. x² + 9x + 20. أزواج 20: 1·20 و2·10 و4·5. المجموع 9 يأتي من 4 و5. الجواب: (x + 4)(x + 5).
مثال 2. x² − 11x + 24. c موجب وb سالب فالعددان سالبان. أزواج 24 التي مجموعها 11: 3 و8. إذن −3 و−8. الجواب: (x − 3)(x − 8).
مثال 3. x² + x − 12. c سالب فالإشارتان مختلفتان. الضرب −12 والمجموع +1: العددان 4 و−3. الجواب: (x + 4)(x − 3). تحقق بـ FOIL: x² − 3x + 4x − 12 = x² + x − 12 ✓.
مثال 4. x² − 2x − 35. الضرب −35 والمجموع −2: العددان −7 و5. الجواب: (x − 7)(x + 5).
مثال 5 (GCF أولاً). 3x² + 18x + 24 = 3(x² + 6x + 8) = 3(x + 2)(x + 4).
مثال 6 (متغيران). x² + 5xy + 6y² = (x + 2y)(x + 3y).

أخطاء شائعة

⚠️ 1) اختيار عددين حاصل ضربهما c لكن مجموعهما خاطئ (مثلاً −5 و2 مجموعهما −3 وليس 3). 2) خلط الإشارات في القوسين النهائيين. 3) نسيان إخراج العامل المشترك أولاً. 4) عدم التحقق بـ FOIL.

ركن الامتحان

سؤال Q4 يطلب "حلّل ثلاثية الحدود". اكتب العددين اللذين وجدتهما (ضع بجانب عملك "الضرب = c، المجموع = b")، ثم الصورة المحللة، وتحقق بـ FOIL إن بقي وقت. بعض الأسئلة مسائل مساحة أو مسائل كلامية حيث العاملان هما طول المستطيل وعرضه.

ملخص سريع

  • لـ x² + bx + c أوجد m وn بحيث m·n = c وm + n = b.
  • الناتج: (x + m)(x + n).
  • c موجب: إشارتان متشابهتان؛ c سالب: إشارتان مختلفتان.
  • أخرج GCF أولاً إن وُجد.
  • تحقق دائماً بـ FOIL.

اختبر نفسك: أسئلة على تحليل ثلاثية الحدود <span class="m">x² + bx + c</span>

حلّل: x² + 7x + 12

✅ الجواب: (x + 3)(x + 4)

3 × 4 = 12 و 3 + 4 = 7.

حلّل: x² − 5x + 6

✅ الجواب: (x − 2)(x − 3)

(−2)(−3) = 6 و (−2) + (−3) = −5.

حلّل: x² + 2x − 15

✅ الجواب: (x + 5)(x − 3)

5 × (−3) = −15 و 5 + (−3) = 2.

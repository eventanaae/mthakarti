أعداد التأكسد في الصيغ المعقدة

⚗️ الكيمياء (متقدم)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q9 · ص 9-10

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

في الصيغ المعقدة نطبق القواعد نفسها خطوة بخطوة: نعوّض الأعداد المعروفة (المجموعة 1 و2، O، H، F) ثم نحل معادلة للمجهول.

K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 ← 2Cr = +12 ← Cr = +6
Al₂(SO₄)₃: Al = +3، والأيون SO₄²⁻: S + 4(−2) = −2 ← S = +6
(NH₄)₂Cr₂O₇: الأيون NH₄⁺ ← N = −3؛ الأيون Cr₂O₇²⁻ ← Cr = +6
NH₄NO₃: في NH₄⁺ N = −3، وفي NO₃⁻ N = +5 (ذرتا نيتروجين بعددين مختلفين!)
Ca(ClO₄)₂: Ca = +2 ← كل ClO₄⁻ شحنته −1 ← Cl = +7
S₂O₃²⁻: 2S − 6 = −2 ← S = +2؛ C₂O₄²⁻: 2C − 8 = −2 ← C = +3
LiAlH₄: Li = +1، Al = +3 ← 4H = −4 ← H = −1 (هيدريد)
نصيحة: إذا احتوى المركب أيوناً متعدد الذرات معروفاً، افصله وحل كل أيون على حدة باستخدام شحنته.
⚠️ قد يظهر عدد تأكسد كسري كمتوسط، مثل Fe في Fe₃O₄ = +8/3، لأنه يحتوي Fe²⁺ وFe³⁺ معاً.

الفكرة بالتفصيل

الصيغ المعقدة تحتوي عدة عناصر أو أيونات متعددة الذرات أو مجموعات مكررة بين أقواس. القواعد هي نفسها في الدرس السابق، لكن عليك تطبيقها بتنظيم. الاستراتيجية: (1) ضع كل ما تعرفه يقيناً (فلزات المجموعتين 1 و2 وF وO وH)؛ (2) إذا وُجد أيون متعدد الذرات معروف فعامله على حدة مستخدماً شحنته؛ (3) اكتب معادلة واحدة للمجهول وحلّها.

لماذا تنجح الاستراتيجية؟

لا يبقى إلا مجهول واحد إذا نفذت الخطوتين الأوليين جيداً، وقاعدة "مجموع أعداد التأكسد = الشحنة الكلية" تعطيك معادلة واحدة. وفصل الأيونات مهم: في NH₄NO₃ ذرتا النيتروجين في أيونين مختلفين فلهما عددا تأكسد مختلفان. ولو عاملت الصيغة كلها وحدة واحدة لحصلت على متوسط خاطئ.

أمثلة محلولة

مثال 1: Cr في K₂Cr₂O₇. K = +1 (×2)، O = −2 (×7). 2(+1) + 2Cr + 7(−2) = 0 ← 2 + 2Cr − 14 = 0 ← 2Cr = +12 ← Cr = +6.
مثال 2: النيتروجين في NH₄NO₃. نفصل إلى NH₄⁺ وNO₃⁻.
في NH₄⁺: N + 4(+1) = +1 ← N = −3.
في NO₃⁻: N + 3(−2) = −1 ← N = +5.
إذن في الصيغة نفسها نيتروجين بعددي تأكسد −3 و+5.
مثال 3: Fe في K₄Fe(CN)₆. K = +1 (×4 = +4). كل CN⁻ يساوي −1 (×6 = −6). المجموع = 0: +4 + Fe − 6 = 0 ← Fe = +2.
مثال 4: S في S₂O₃²⁻ (ثيوكبريتات): 2S + 3(−2) = −2 ← 2S = +4 ← S = +2 (متوسط). وفي Ca(ClO₄)₂: Ca = +2 فكل ClO₄⁻ يساوي −1: Cl + 4(−2) = −1 ← Cl = +7.
⚠️ أخطاء شائعة: (1) مع الأقواس مثل Al₂(SO₄)₃ تذكّر أن الرمز 3 يضاعف كل ما داخل القوس: 3 أيونات كبريتات. (2) الكسور ممكنة: في Fe₃O₄: 3Fe + 4(−2) = 0 ← Fe = +8/3 (متوسط Fe²⁺ وFe³⁺). المتوسط لا يعني أن الذرات الحقيقية تحمل شحنة كسرية. (3) لا تنسَ شحنة الأيون إذا لم يكن متعادلاً.
ركن الامتحان (Q9): يعطي Q9 صيغة معقدة ويطلب عدد تأكسد عنصر واحد. اكتب سطر المعادلة. وإذا احتوت الصيغة أيوناً معروفاً (SO₄²⁻ وNO₃⁻ وNH₄⁺ وCN⁻ وClO₄⁻) ففصله أولاً. تضيع العلامات عادة في ضرب الأقواس ونسيان أن K وNa (المجموعة 1) وCa وMg (المجموعة 2) ثابتة.

ملخص سريع

  • ضع القيم المعروفة، افصل الأيونات متعددة الذرات، ثم حلّ معادلة واحدة.
  • اضرب في الرموز السفلية (وفي أرقام الأقواس).
  • قد يكون للعنصر نفسه أعداد تأكسد مختلفة في أيونات الصيغة الواحدة.
  • القيم المتوسطة (مثل +8/3) ممكنة.

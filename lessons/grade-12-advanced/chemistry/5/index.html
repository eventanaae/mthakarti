قواعد تحديد أعداد التأكسد

⚗️ الكيمياء (متقدم)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q7-Q8 · ص 9-10 (جدول 3)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
  1. عدد تأكسد الذرة غير المرتبطة (العنصر الحر) = صفر: Na، O₂، Cl₂، P₄.
  2. عدد تأكسد الأيون أحادي الذرة = شحنته: Ca²⁺ = +2، Br⁻ = −1.
  3. العنصر الأعلى سالبية في المركب يأخذ عدد تأكسد سالباً يساوي شحنة أيونه المعتادة.
  4. الفلور دائماً −1 في مركباته.
  5. الأكسجين −2 غالباً، إلا في فوق الأكاسيد مثل H₂O₂ فيكون −1، ومع الفلور OF₂ يكون +2.
  6. الهيدروجين +1 مع العناصر الأعلى سالبية، و−1 مع الفلزات (الهيدريدات مثل NaH).
  7. فلزات المجموعة 1 دائماً +1، والمجموعة 2 دائماً +2، والألومنيوم +3 في مركباتها.
  8. مجموع أعداد التأكسد في المركب المتعادل = صفر.
  9. مجموع أعداد التأكسد في الأيون متعدد الذرات = شحنة الأيون.
Na₂SO₄: 2(+1) + S + 4(−2) = 0 ← S = +6
PO₄³⁻: P + 4(−2) = −3 ← P = +5
NO₃⁻: N + 3(−2) = −1 ← N = +5
NH₄⁺: N + 4(+1) = +1 ← N = −3
KMnO₄: +1 + Mn − 8 = 0 ← Mn = +7
NaClO₃: +1 + Cl − 6 = 0 ← Cl = +5
⚠️ اضرب عدد التأكسد في عدد الذرات قبل الجمع، وتذكّر أن مجموع الأيون يساوي شحنته وليس صفراً.

الفكرة بالتفصيل

لاستخدام أعداد التأكسد تحتاج إلى قواعد لتحديدها. تُطبَّق بالترتيب، وإذا تعارضت قاعدتان تفوز الأعلى في القائمة.

القاعدةأمثلة
1. العنصر الحر (ذرة غير متحدة): صفرNa وO₂ وCl₂ وP₄ وS₈
2. الأيون أحادي الذرة: يساوي شحنتهCa²⁺ = +2، Br⁻ = −1
3. الفلور: دائماً −1HF وCaF₂
4. المجموعة 1 = +1، المجموعة 2 = +2، Al = +3NaCl وMgO وAlCl₃
5. الهيدروجين: +1 (مع اللافلزات)، −1 (في هيدريدات الفلزات)H₂O (+1)، NaH (−1)
6. الأكسجين: −2 غالباً؛ −1 في البيروكسيدات؛ +2 في OF₂H₂O (−2)، H₂O₂ (−1)
7. مجموع الأعداد في مركّب متعادل = صفرNa₂SO₄
8. مجموع الأعداد في أيون متعدد الذرات = شحنة الأيونSO₄²⁻ = −2

لماذا تعمل هذه القواعد؟

مصدرها السالبية الكهربائية. الفلور أعلى العناصر سالبية فيربح الإلكترونات دائماً (−1). والأكسجين ثاني أعلى سالبية فيربحها في معظم المركّبات. وفلزات المجموعتين 1 و2 تفقد عدداً ثابتاً من الإلكترونات بسهولة. أما قاعدتا المجموع فهما حفظ الشحنة: لا بد أن يطابق المجموع ما يحمله الأيون أو الجزيء فعلاً.

أمثلة محلولة

مثال 1: الكبريت في H₂SO₄. H = +1 وO = −2. المركّب متعادل: 2(+1) + S + 4(−2) = 0 ← 2 + S − 8 = 0 ← S = +6.
مثال 2: الكلور في ClO₃⁻. المجموع يساوي −1: Cl + 3(−2) = −1 ← Cl = +5.
مثال 3: المنغنيز في MnO₄²⁻ (منغنات): Mn + 4(−2) = −2 ← Mn = +6. قارنه بـ MnO₄⁻ (برمنغنات): Mn = +7.
مثال 4: الكربون في CH₄: C + 4(+1) = 0 ← C = −4. وفي CO₂: C + 2(−2) = 0 ← C = +4. العنصر نفسه بقيمتين شديدتي الاختلاف: من −4 إلى +4 أي فقد 8 إلكترونات عند احتراق الميثان.
⚠️ أخطاء شائعة: (1) نسيان الضرب في عدد الذرات: في Na₂SO₄ يوجد 2 Na و4 O. (2) جعل مجموع الأيون صفراً؛ بل يساوي شحنته. (3) استخدام O = −2 في البيروكسيدات (H₂O₂ وNa₂O₂): هناك يساوي −1. (4) استخدام H = +1 في الهيدريدات (NaH وLiAlH₄): هناك يساوي −1.
ركن الامتحان (Q7-Q8): يُسأل "ما عدد تأكسد X في المركّب/الأيون Y؟" وأحياناً الترتيب أو المقارنة. طريقة العلامة الكاملة: اكتب المعادلة (مثل "S + 4(−2) = −2") ثم حلّها وأعطِ الإشارة. وإذا ظهرت قيمة غريبة (مثل +1.5) فراجع عدد الذرات. ويستخدم Q7-Q8 الجدول 3 في الكتاب، وهو الجدول أعلاه.

ملخص سريع

  • العنصر الحر = 0؛ الأيون أحادي الذرة = شحنته.
  • F = −1؛ المجموعة 1 = +1؛ المجموعة 2 = +2؛ Al = +3.
  • H = +1 (و−1 في الهيدريدات)؛ O = −2 (و−1 في البيروكسيدات).
  • المركّب المتعادل مجموعه 0؛ والأيون مجموعه شحنته.

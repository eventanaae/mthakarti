وزن معادلات الأكسدة والاختزال في الوسط الحمضي

⚗️ الكيمياء (متقدم)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q14-Q15 · ص 16-19 (مثال محلول 5)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
مثال محلول: KMnO₄ + SnCl₂ + HCl → MnCl₂ + SnCl₄ + H₂O + KCl
المعادلة الأيونية: MnO₄⁻ + Sn²⁺ → Mn²⁺ + Sn⁴⁺
أكسدة: Sn²⁺ → Sn⁴⁺ + 2e⁻ (×5)
اختزال: MnO₄⁻ → Mn²⁺ + 4H₂O ثم 8H⁺ + MnO₄⁻ → Mn²⁺ + 4H₂O ثم 5e⁻ + 8H⁺ + MnO₄⁻ → Mn²⁺ + 4H₂O (×2)
المضاعف المشترك للعددين 2 و5 = 10.
النهائية: 2MnO₄⁻ + 5Sn²⁺ + 16H⁺ → 2Mn²⁺ + 5Sn⁴⁺ + 8H₂O
الشحنة: −2 + 10 + 16 = +24 ؛ 4 + 20 = +24 ✔
بإرجاع المتفرجات: 2KMnO₄ + 5SnCl₂ + 16HCl → 2MnCl₂ + 5SnCl₄ + 8H₂O + 2KCl
أنصاف تفاعلات مهمة في الوسط الحمضي:
MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O
NO₃⁻ + 4H⁺ + 3e⁻ → NO + 2H₂O
SO₂ + 2H₂O → SO₄²⁻ + 4H⁺ + 2e⁻
MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O
Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O
2MnO₄⁻ + 5SO₂ + 2H₂O → 2Mn²⁺ + 5SO₄²⁻ + 4H⁺
2MnO₄⁻ + 10I⁻ + 16H⁺ → 2Mn²⁺ + 5I₂ + 8H₂O
⚠️ معادلة موزونة ذرياً قد تكون غير موزونة في الشحنة: Fe²⁺ + Cr₂O₇²⁻ + 14H⁺ → Fe³⁺ + 2Cr³⁺ + 7H₂O شحنة متفاعلاتها +14 ونواتجها +9، والصحيح وضع 6 أمام Fe²⁺ وFe³⁺.

الفكرة بالتفصيل

في الوسط الحمضي يتوافر الكثير من أيونات H⁺ والماء، فهذان هما الأداتان الوحيدتان المسموح بهما لوزن الأكسجين والهيدروجين. تحتوي المعادلة النهائية على H⁺ (إذا لزم) وH₂O ولا تحتوي OH⁻.

لماذا نضيف H₂O أولاً ثم H⁺؟

كثير من أنصاف تفاعلات الأكسدة والاختزال يغيّر عدد ذرات الأكسجين (مثلاً MnO₄⁻ ← Mn²⁺ يفقد أربع ذرات O). في الماء لا بد أن يذهب الأكسجين إلى مكان: يخرج على شكل H₂O. وتكوين H₂O يحتاج هيدروجين، يوفره الحمض على شكل H⁺. وبعد وزن الأكسجين والهيدروجين يبقى عدم التوازن في الشحنة فقط، وتصلحه الإلكترونات. هذا الترتيب (الذرات، O، H، الشحنة) لا يخطئ.

أمثلة محلولة

مثال 1: ثنائي الكرومات وأيون الحديد II. Cr₂O₇²⁻ + Fe²⁺ → Cr³⁺ + Fe³⁺ (حمضي)
نصف الاختزال: Cr₂O₇²⁻ → 2Cr³⁺ (وزن Cr). نضيف 7H₂O إلى اليمين لـ O: Cr₂O₇²⁻ → 2Cr³⁺ + 7H₂O. نضيف 14H⁺ إلى اليسار لـ H: Cr₂O₇²⁻ + 14H⁺ → 2Cr³⁺ + 7H₂O. الشحنة: يسار −2 + 14 = +12؛ يمين +6. نضيف 6e⁻ إلى اليسار: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O.
نصف الأكسدة: Fe²⁺ → Fe³⁺ + e⁻ نضربه في 6.
بالجمع: Cr₂O₇²⁻ + 14H⁺ + 6Fe²⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O. الشحنة: −2 + 14 + 12 = +24؛ 6 + 18 = +24 ✓.
مثال 2: النحاس والنترات. Cu + NO₃⁻ → Cu²⁺ + NO (حمضي)
الأكسدة: Cu → Cu²⁺ + 2e⁻. الاختزال: NO₃⁻ → NO + 2H₂O ثم NO₃⁻ + 4H⁺ → NO + 2H₂O، الشحنة: يسار +3، يمين 0، فنضيف 3e⁻ يساراً: NO₃⁻ + 4H⁺ + 3e⁻ → NO + 2H₂O.
المضاعف المشترك الأصغر للعددين 2 و3 هو 6: الأكسدة ×3 والاختزال ×2.
3Cu + 2NO₃⁻ + 8H⁺ → 3Cu²⁺ + 2NO + 4H₂O. الشحنة: −2 + 8 = +6؛ +6 ✓. O: 6 = 2 + 4 ✓. H: 8 = 8 ✓.
مثال 3: البرمنغنات وفوق أكسيد الهيدروجين. الاختزال: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (×2). الأكسدة: H₂O₂ → O₂ + 2H⁺ + 2e⁻ (×5). بالجمع: 2MnO₄⁻ + 5H₂O₂ + 6H⁺ → 2Mn²⁺ + 5O₂ + 8H₂O (المعاملان ×2 و×5 يعطيان 16H⁺ يساراً و10H⁺ يميناً، وبالحذف يبقى 6H⁺ يساراً). التحقق: H: 10 + 6 = 16 = 16 ✓؛ O: 8 + 10 = 18 = 10 + 8 ✓؛ الشحنة: −2 + 6 = +4 = +4 ✓.
⚠️ أخطاء شائعة: (1) وزن H قبل O؛ زِن O أولاً بالماء. (2) نسيان وزن الشحنة؛ قد تكون الذرات صحيحة والشحنة خاطئة. (3) عدم حذف H⁺ وH₂O الظاهرين في الطرفين بعد الجمع. (4) استخدام نصف تفاعل MnO₄⁻ ← MnO₂ في مسألة حمضية (في الحمض يتحول البرمنغنات عادة إلى Mn²⁺).
ركن الامتحان (Q14-Q15): يعطي Q14 عادة معادلة غير موزونة في وسط حمضي ويطلب معامل H⁺ أو H₂O أو عدد الإلكترونات في المعادلة الموزونة. ويطلب Q15 المعادلة الموزونة كاملة. نصيحة: بعد الوزن تحقق من مجموع الشحنات؛ إذا تساوى الطرفان وتطابق عدد O فأنت على صواب. احفظ أنصاف التفاعل المعيارية: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O وCr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O.

ملخص سريع

  • الوسط الحمضي: استخدم H₂O وH⁺ فقط (لا OH⁻ ولا O₂).
  • الترتيب: الذرات، O (H₂O)، H (H⁺)، الشحنة (e⁻)، مساواة الإلكترونات.
  • MnO₄⁻ ← Mn²⁺ يأخذ 5e⁻ و8H⁺؛ وCr₂O₇²⁻ ← 2Cr³⁺ يأخذ 6e⁻ و14H⁺.
  • تحقق من الشحنة في النهاية.

اختبر نفسك: أسئلة على وزن معادلات الأكسدة والاختزال في الوسط الحمضي

ما نصف تفاعل الاختزال الموزون لـ MnO₄⁻ → Mn²⁺ في وسط حمضي؟

✅ الجواب: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O

الشحنة: −1 + 8 − 5 = +2.

عند وزن MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺ في وسط حمضي، ما معامل Fe²⁺؟

✅ الجواب: 5

Mn يكسب 5e⁻ وكل Fe يفقد 1e⁻.

ما المعادلة الموزونة لتفاعل Cr₂O₇²⁻ مع Fe²⁺ في وسط حمضي؟

✅ الجواب: Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O

الشحنة +24 في الطرفين والإلكترونات 6.

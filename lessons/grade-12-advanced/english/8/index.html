Grammar 2: Comparatives

The idea in detail

A comparative adjective compares two things: "A living roof is cooler than a black roof." To form it you need to know the number of syllables (the beats in a word: cool = 1, heavy = 2, sus-tain-a-ble = 4).

TypeRuleExamples
1 syllable+ -ercool → cooler, cheap → cheaper, long → longer
1 syllable, consonant-vowel-consonantdouble last consonant + -erhot → hotter, big → bigger
2 syllables ending in -y-y → -ierheavy → heavier, noisy → noisier
2+ syllablesmore / less + adjectivemore sustainable, less expensive
Irregularlearn by heartgood → better, bad → worse, far → further/farther

Other comparing patterns

  • Modifiers show the size of the difference: much, far, a lot (big) and slightly, a bit, a little (small): "much cooler", "slightly cheaper".
  • (not) as + adjective + as: "A gravel roof is not as good as a living roof." The meaning is the same as "A living roof is better than a gravel roof".
  • The + comparative, the + comparative: two changes that go together. "The more plants there are, the cooler the building becomes."
  • Comparing with nouns: more / fewer / less + noun: "more plants", "fewer insects" (countable), "less water" (uncountable).

Why / how it works

The comparative is like a scale with two people standing on it: you say which one is higher. We need than to introduce the second item. Short adjectives take -er because they are easy to say; long adjectives would sound heavy with -er, so English uses more in front. The doubling rule keeps the vowel sound short: hot + ter = "hotter" (if we wrote "hoter" it would sound like "hoater").

Worked example 1

Complete using the correct comparative form.
a) "In July, a black roof is much ____ (hot) than a green roof." hot ends consonant-vowel-consonant (h-o-t) → double t → hotter.
b) "Green roofs are ____ (expensive) to install than ordinary roofs." 3 syllables (ex-pen-sive) → more expensive.
c) "Living roofs are ____ (good) for wildlife than gravel roofs." irregular → better.
d) "A concrete road is ____ (noisy) than a grass path." -y ending → noisier.

Worked example 2

Rewrite with not as ... as: "A gravel roof is worse for biodiversity than a living roof." → A gravel roof is not as good as a living roof for biodiversity. (worse → not as good as: we change to the opposite adjective.)
Join with the ... the: "More plants grow. The building becomes cooler." → The more plants grow, the cooler the building becomes.

Common mistakes

⚠️ 1) Double comparison: "more cooler" ✗ → "cooler" ✓. 2) "then" instead of "than" ("cooler then") - "than" compares; "then" is about time. 3) "very cheaper" ✗ → "much cheaper" ✓ (very cannot be used before a comparative). 4) Forgetting to double the consonant (hoter ✗). 5) Using -er with long adjectives ("expensiver" ✗). 6) In "the ... the" patterns, dropping the second "the".

Exam corner

How it is asked: "Part 2 - Comparatives." Gap-fill such as "In summer, a dark roof gets much ____ than a green roof" with options like hotter / hoter / more hot. Full marks: (1) count syllables; (2) check spelling rules (doubling, y → ier); (3) look for "than" which shows a comparative is needed (and "the" before an adjective with no "than" might be a superlative); (4) eliminate double forms like "more cooler".

Quick summary

  • 1 syllable: +er (cooler); CVC: double (hotter); -y: -ier (heavier); long: more/less.
  • Irregular: better, worse, further.
  • much / far / a lot = big difference; slightly / a bit = small difference. Never "very".
  • (not) as ... as; the more ..., the ...er.
  • Use than, not then.

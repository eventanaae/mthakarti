مشتقات الدوال اللوغاريتمية الطبيعية

📈 الرياضيات (التفاضل والتكامل)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q17 · ص 193 (20-22)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
d/dx (ln x) = 1/x (x > 0)، d/dx (ln|x|) = 1/x
d/dx (ln g(x)) = g′(x)/g(x)
d/dx (logₐ x) = 1/(x ln a)

بسّط بخصائص اللوغاريتمات قبل الاشتقاق: ln(ab) = ln a + ln b، ln(aⁿ) = n ln a، e^(ln x) = x.

f(x) = √(ln x)/x:
f′ = (x·(1/(2√(ln x)))·(1/x) − √(ln x))/x² = (1 − 2ln x)/(2x²√(ln x))
g(t) = ln√t / t: g′ = (1 − 2ln√t)/(2t²) (أو (1 − ln t)/(2t²)).
h(x) = eˣ ln x ⇐ h′ = eˣ ln x + eˣ/x = eˣ(ln x + 1/x)
f(x) = e^(ln x) = x ⇐ f′ = 1
y = ln(x² + 1) ⇐ y′ = 2x/(x² + 1)
الاشتقاق اللوغاريتمي (logarithmic differentiation): لـ y = xˣ: ln y = x ln x ⇐ y′/y = ln x + 1 ⇐ y′ = xˣ(ln x + 1).
⚠️ ln(x² + 1) ≠ 2 ln x + 1. ولا تستخدم قاعدة القوة ولا قاعدة الأسية مع xˣ؛ استخدم الاشتقاق اللوغاريتمي.

الفكرة بالتفصيل

اللوغاريتم الطبيعي (natural logarithm) ln x هو اللوغاريتم للأساس e: وهو عكس eˣ، فـ ln(eˣ) = x و e^(ln x) = x. ويُعرَّف عندما x > 0. مشتقاته:

d/dx (ln x) = 1/x (x > 0)
d/dx (ln u) = u′/u (قاعدة السلسلة)
d/dx (ln|x|) = 1/x (x ≠ 0)
d/dx (loga x) = 1/(x ln a)

استخدم قوانين اللوغاريتم قبل الاشتقاق

قوانين اللوغاريتمات تحوّل مشتقة صعبة إلى سهلة:

  • ln(ab) = ln a + ln b
  • ln(a/b) = ln a − ln b
  • ln(aⁿ) = n ln a

الاشتقاق اللوغاريتمي (logarithmic differentiation)

للاقترانات مثل xˣ (المتغير في الأساس والأس معاً) أو حواصل الضرب الطويلة: خذ ln للطرفين، واشتق ضمنياً، ثم اضرب في y.

لماذا يعمل هذا؟

بما أن ln عكس eˣ فتنطبق قاعدة مشتقة العكسي: إذا كانت y = ln x فإن eʸ = x، فـ eʸ·y′ = 1 و y′ = 1/eʸ = 1/x. وحدسياً ln ينمو ببطء شديد: عند x = 1 ميله 1، وعند x = 100 ميله 0.01 فقط، فينبسط المنحنى.

أمثلة محلولة

مثال 1: قاعدة السلسلة. y = ln(x² + 1): y′ = 2x/(x² + 1).
مثال 2: بسّط أولاً. y = ln((x + 1)/(x − 2)) (عندما x > 2).
نعيد الكتابة: y = ln(x + 1) − ln(x − 2).
y′ = 1/(x + 1) − 1/(x − 2) = ((x − 2) − (x + 1))/((x + 1)(x − 2)) = −3/((x + 1)(x − 2)).
مثال 3: ضرب. y = x ln x: y′ = 1·ln x + x·(1/x) = ln x + 1. عند x = e: y′ = 1 + 1 = 2.
مثال 4: اشتقاق لوغاريتمي. y = xˣ (x > 0).
ln y = x ln x. نشتق: y′/y = ln x + 1.
إذن y′ = xˣ(ln x + 1).
مثال 5: أساس آخر. y = log₂(3x): y′ = 3/(3x ln 2) = 1/(x ln 2).

أخطاء شائعة

⚠️ 1) نسيان مشتقة الداخلي: (ln 5x)′ = 1/x وهي 5/(5x) (كثيرون يكتبون 1/(5x)). 2) اشتقاق ln(a + b) على أنه ln a + ln b؛ لا يوجد قانون كهذا للمجموع. 3) استخدام قاعدة القسمة على ln(a/b) بينما التفكيك أسهل بكثير. 4) نسيان المجال (يجب أن يكون ما داخل ln موجباً). 5) نسيان 1/ln a في الأسس الأخرى.

ركن الاختبار

يأتي هذا البند بوصف Q17 · ص 193 (20-22) اختيار من متعدد: اشتق اقتراناً فيه ln، وغالباً تركيب مثل ln(x² + 1) أو حاصل ضرب مع قوة من x أو قسمة داخل لوغاريتم. افحص دائماً هل تبسّط قوانين اللوغاريتم التعبير أولاً، فيصير الحل سطرين. وعوّض x = 1 (ln 1 = 0) لاختبار الخيارات.

ملخص سريع

  • (ln x)′ = 1/x؛ (ln u)′ = u′/u.
  • (loga x)′ = 1/(x ln a).
  • استخدم قوانين اللوغاريتم للفك قبل الاشتقاق.
  • الاشتقاق اللوغاريتمي يحلّ xˣ وحواصل الضرب الطويلة.
  • ln معرّف للقيم الموجبة فقط.

اختبر نفسك: أسئلة على مشتقات الدوال اللوغاريتمية الطبيعية

✅ الجواب: (1 − 2ln√t)/(2t²)

✅ الجواب: ex(ln x + 1/x)

نظرية الشطيرة (Squeeze Theorem)

📈 الرياضيات (التفاضل والتكامل)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q3 · ص 85 (29-32)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
نظرية الشطيرة (الساندويتش): إذا كان f(x) ≤ g(x) ≤ h(x) لكل x قريبة من a، وكان limx→a f(x) = limx→a h(x) = L، فإن limx→a g(x) = L.

نستخدمها عندما يحتوي التعبير على دالة متذبذبة (oscillating) مثل sin(1/x) أو cos(1/x) التي ليس لها نهاية عند 0.

أوجد limx→0 x² sin(1/x):
1) −1 ≤ sin(1/x) ≤ 1
2) نضرب في x² ≥ 0 (لا تنعكس المتباينة): −x² ≤ x² sin(1/x) ≤ x²
3) lim (−x²) = 0 = lim x² ⇐ النهاية = 0.
limx→0⁺ x cos²(1/x): بما أن 0 ≤ cos²(1/x) ≤ 1 و x > 0 فإن 0 ≤ x cos²(1/x) ≤ x ⇐ النهاية = 0.
إذا كان 4x − 9 ≤ f(x) ≤ x² − 4x + 7 لكل x ≥ 0 فإن عند x = 4 الطرفان يساويان 7 ⇐ limx→4 f(x) = 7.
⚠️ لا يجوز كتابة lim x² · lim sin(1/x) لأن lim sin(1/x) غير موجودة. ويجب أن تتساوى نهايتا الدالتين المحيطتين، وإلا لا نستنتج شيئاً.

الفكرة بالتفصيل

بعض الدوال أشدّ شراسة من أن تتعامل معها قوانين النهايات. خذ x·sin(1/x) قرب 0: العامل sin(1/x) يتذبذب بين −1 و 1 بسرعة لانهائية وليست له نهاية، فلا نستطيع تفكيك حاصل الضرب. هنا تنقذنا نظرية الشطيرة (Squeeze Theorem) وتسمى أيضاً نظرية الساندويتش.

نظرية الشطيرة: إذا كان f(x) ≤ g(x) ≤ h(x) لكل x قرب a (ما عدا ربما عند a) وكانت lim f(x) = lim h(x) = L فإن lim g(x) = L.

طريقة الاستخدام خطوة بخطوة

  1. حدّد الدالة المتذبذبة المحدودة: −1 ≤ sin(أي شيء) ≤ 1 و 0 ≤ cos²(أي شيء) ≤ 1.
  2. اضرب المتباينة في العامل الآخر. إذا كان هذا العامل قد يكون سالباً تنقلب المتباينة، لذا استخدم القيمة المطلقة أو عاملاً غير سالب دائماً مثل x² أو |x|.
  3. أوجد نهايتي الحد الأدنى والحد الأعلى. إذا تساوتا فقد انتهيت.

لماذا يعمل هذا؟

تخيّل جدارين يضيقان على بعضهما في ممر وأنت محصور بينهما. إذا وصل الجداران إلى النقطة نفسها فلا بد أنك تصل إليها أيضاً مهما تلوّيت. الدالتان المحيطتان هما الجداران، و g(x) هي أنت. التذبذب مسموح لكنه محبوس.

أمثلة محلولة

مثال 1: limx→0 x·sin(1/x).
نعلم أن −1 ≤ sin(1/x) ≤ 1. بالضرب في |x| ≥ 0 نحصل على −|x| ≤ x·sin(1/x) ≤ |x| (صحيح لأن |x·sin(1/x)| = |x|·|sin(1/x)| ≤ |x|).
عندما x → 0 تتجه −|x| و |x| إلى 0، إذن النهاية 0.
مثال 2: نهاية عند اللانهاية. limx→∞ (sin x)/x.
عندما x > 0: −1/x ≤ (sin x)/x ≤ 1/x. كلا الحدين يتجه إلى 0 عندما x → ∞، إذن النهاية 0.
مثال 3: حدود معطاة. افترض أن 2x ≤ f(x) ≤ x² + 1 لكل x. أوجد limx→1 f(x).
(تحقق: x² + 1 − 2x = (x − 1)² ≥ 0 فالحدود متسقة.) عند x = 1: الحد الأدنى = 2 والحد الأعلى = 1² + 1 = 2. متساويان، إذن lim f(x) = 2.

أخطاء شائعة

⚠️ 1) تفكيك نهاية حاصل الضرب عندما لا يكون لأحد العاملين نهاية، مثل كتابة lim x · lim sin(1/x). 2) الضرب في عدد سالب دون قلب المتباينة. 3) استخدام دالتين محيطتين نهايتاهما مختلفتان: عندها لا تعطي النظرية أي نتيجة. 4) نسيان كتابة الحدّ المعروف (−1 ≤ sin ≤ 1) في الحل المكتوب. 5) كتابة النتيجة دون ذكر أن الحدّين يتجهان إلى القيمة نفسها.

ركن الاختبار

يأتي هذا البند بوصف Q3 · ص 85 (29-32). سيُعطى لك تعبير فيه sin(1/x) أو cos(1/x) مضروباً في قوة من x، أو دالة محصورة بين تعبيرين معطيين. الحل النموذجي من أربعة أسطر: (1) الحد المعروف، (2) المتباينة بعد الضرب، (3) نهاية كل طرف، (4) الخلاصة "بنظرية الشطيرة النهاية L". وفي صيغة الحدود المعطاة يكفي أن تحسب الحدّين عند a وتتأكد أنهما متساويان.

ملخص سريع

  • إذا كانت g محصورة بين f و h ولهما النهاية L نفسها فنهاية g تساوي L.
  • تُستخدم عند وجود عامل متذبذب مثل sin(1/x).
  • ابدأ من −1 ≤ sin(…) ≤ 1 واضرب في عامل غير سالب.
  • يجب أن يتجه الحدّان إلى العدد نفسه.
  • limx→∞ sin x / x = 0 تأتي من هذه النظرية.

تطبيق قاعدة الضرب: معادلة المماس

📈 الرياضيات (التفاضل والتكامل)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q23 مقالي · ص 169 (17-20)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

في السؤال المقالي يُطلب عادة إيجاد معادلة المماس (tangent line) لـ y = f(x) عند x = a حيث f حاصل ضرب دالتين.

الخطوات:
1) احسب f(a) لتحصل على النقطة.
2) اشتق بقاعدة الضرب: f′ = u′v + uv′.
3) عوّض لتحصل على الميل m = f′(a).
4) اكتب y − f(a) = m(x − a).
f(x) = (x² + 2x)(x⁴ + x² + 1) عند a = 0:
f(0) = 0، f′(x) = (2x + 2)(x⁴ + x² + 1) + (x² + 2x)(4x³ + 2x)
f′(0) = 2(1) + 0 = 2 ⇐ المماس y = 2x.
f(x) = (x³ + x + 1)(3x² + 2x − 1) عند a = 1:
f(1) = 3 × 4 = 12
f′(1) = (3 + 1)(4) + (3)(6 + 2) = 16 + 24 = 40
المماس: y − 12 = 40(x − 1) ⇐ y = 40x − 28.
مع دالة مجهولة: f(x) = x²·g(x)، g(2) = 3، g′(2) = −1 ⇐ f′(2) = 2(2)(3) + 4(−1) = 8.
⚠️ لا تعوّض a قبل الاشتقاق. واكتب كل الخطوات في المقالي: الدرجة على الطريقة لا على الجواب فقط.

الفكرة بالتفصيل

أهم استخدامات المشتقة هو المماس (tangent line). إذا عرفت f(a) و f′(a) فإن المماس لـ y = f(x) عند x = a هو

y − f(a) = f′(a)·(x − a)

والخط العمودي على المماس عند نقطة التماس هو العمودي (normal line) وميله −1/f′(a) (عندما f′(a) ≠ 0).

خطوات سؤال مقالي عن المماس

  1. أوجد قيمة y: احسب f(a) لتحصل على النقطة (a, f(a)).
  2. اشتق بالقاعدة المناسبة (هنا غالباً قاعدة الضرب).
  3. عوّض x = a في f′ لتحصل على الميل m.
  4. اكتب المستقيم بصيغة النقطة والميل ثم بسّطه إلى y = mx + b إن طُلب.

أسئلة خاصة عن المماس

  • مماس أفقي: حلّ f′(x) = 0.
  • مماس يوازي مستقيماً معطى: ساوِ f′(x) بميل ذلك المستقيم.
  • مماس عمودي على مستقيم معطى: ساوِ f′(x) بمعكوس الميل السالب.

لماذا يعمل هذا؟

قرب نقطة التماس يكاد المنحنى ومماسه يتطابقان كأنه جزء من طريق شبه مستقيم. ولذلك يُستخدم المماس لتقريب قيم f قرب a. وميل المماس هو بالتعريف المشتقة عند تلك النقطة، فنحتاج نقطة واحدة وميلاً واحداً لتحديد المستقيم.

أمثلة محلولة

مثال 1: المماس والعمودي. أوجد المماس والعمودي لـ f(x) = (x + 1)(x² − 3) عند x = 2.
النقطة: f(2) = 3·1 = 3 فالنقطة (2, 3).
المشتقة (قاعدة الضرب): f′(x) = 1·(x² − 3) + (x + 1)(2x). عند x = 2: 1 + 3·4 = 13.
(تحقق: f = x³ + x² − 3x − 3 و f′ = 3x² + 2x − 3 = 12 + 4 − 3 = 13 ✓.)
المماس: y − 3 = 13(x − 2) ⇒ y = 13x − 23.
العمودي: الميل −1/13: y − 3 = −(1/13)(x − 2).
مثال 2: مماسات أفقية. أين يكون مماس f(x) = x²(x − 3) أفقياً؟
f′(x) = 2x(x − 3) + x²·1 = 3x² − 6x = 3x(x − 2).
بوضع f′ = 0 نحصل على x = 0 أو x = 2. النقطتان: f(0) = 0 فالنقطة (0, 0)؛ و f(2) = 4·(−1) = −4 فالنقطة (2, −4).
مثال 3: موازٍ لمستقيم. عند أي x يوازي مماس f(x) = x³ المستقيم y = 12x + 5؟
f′(x) = 3x² = 12 ⇒ x² = 4 ⇒ x = ±2. النقطتان: (2, 8) و (−2, −8).

أخطاء شائعة

⚠️ 1) استخدام f(a) بدل f′(a) كميل. 2) تعويض x = a في الاقتران الأصلي بدل المشتقة عند إيجاد الميل. 3) نسيان إيجاد الإحداثي y للنقطة. 4) اشتقاق حاصل الضرب على أنه f′g′. 5) في العمودي: نسيان قلب الميل وتغيير إشارته معاً. 6) عدم تبسيط المستقيم النهائي عند طلب y = mx + b.

ركن الاختبار

يأتي هذا البند بوصف Q23 مقالي · ص 169 (17-20). ترتيب الإجابة النموذجية (وغالباً لكل سطر علامة): "f(a) = … فالنقطة (a, …). f′(x) = … (اذكر القاعدة). f′(a) = … = الميل. المماس: y − f(a) = f′(a)(x − a) ⇒ y = …". وإذا طُلب العمودي أضف الميل العمودي. وإذا طُلبت نقطة المماس الأفقي فاكتب f′(x) = 0 وحلّ ثم أوجد قيم y.

ملخص سريع

  • المماس عند x = a: y − f(a) = f′(a)(x − a).
  • ميل العمودي = −1/f′(a).
  • مماس أفقي ⇔ f′(x) = 0؛ والمستقيمان المتوازيان ميلاهما متساويان.
  • أوجد النقطة أولاً ثم الميل ثم المستقيم.

اختبر نفسك: أسئلة على تطبيق قاعدة الضرب: معادلة المماس

معادلة المماس لـ f(x) = (x² + 2x)(x⁴ + x² + 1) عند x = 0:

✅ الجواب: y = 2x

f(0) = 0 و f′(0) = (2)(1) + (0)(0) = 2.

معادلة المماس لـ f(x) = (x³ + x + 1)(3x² + 2x − 1) عند x = 1:

✅ الجواب: y = 40x − 28

f(1) = 12 و f′(1) = (4)(4) + (3)(8) = 40 ⇐ y − 12 = 40(x − 1).

معادلة المماس لـ f(x) = (x + 1)(x² − 2x + 3) عند x = 1:

✅ الجواب: y = 2x + 2

f(1) = 2·2 = 4 و f′(1) = 2 + (2)(0) = 2 ⇐ y − 4 = 2(x − 1).

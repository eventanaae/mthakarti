مشتقات الدوال الأسية

📈 الرياضيات (التفاضل والتكامل)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q16 · ص 194 (29-30)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
d/dx (eˣ) = eˣ، d/dx (e^(g(x))) = g′(x)·e^(g(x))
d/dx (aˣ) = aˣ·ln a، d/dx (a^(g(x))) = a^(g(x))·ln a·g′(x)

المماس الأفقي (horizontal tangent): نحل f′(x) = 0. وبما أن e^(kx) > 0 دائماً، نساوي العوامل الأخرى بالصفر.

f(x) = x e^(−2x): f′ = e^(−2x) − 2x e^(−2x) = e^(−2x)(1 − 2x) = 0 ⇐ x = 1/2.
f(x) = x e^(−3x): f′ = e^(−3x)(1 − 3x) ⇐ x = 1/3.
f(x) = x² e^(−2x): f′ = 2x e^(−2x) − 2x² e^(−2x) = 2x e^(−2x)(1 − x) ⇐ x = 0 أو x = 1.
f(x) = x² e^(−3x): f′ = x e^(−3x)(2 − 3x) ⇐ x = 0 أو x = 2/3.
h(x) = 2^(eˣ) ⇐ h′ = 2^(eˣ)·ln 2·eˣ
f(x) = eˣ/2ˣ ⇐ f′ = (2ˣeˣ − eˣ2ˣ ln 2)/(2ˣ)² = eˣ(1 − ln 2)/2ˣ
⚠️ لا تقسم على x عند الحل؛ أخرجه عاملاً مشتركاً وإلا تخسر الحل x = 0. ولا تطبّق قاعدة القوة على aˣ (الأس متغير).

الفكرة بالتفصيل

الاقتران الأسي الطبيعي (natural exponential function) eˣ (حيث e ≈ 2.71828) مميّز: هو الاقتران الأسي الوحيد الذي ميله عند كل نقطة يساوي قيمته.

d/dx (eˣ) = eˣ
d/dx (e^u) = e^u·u′ (قاعدة السلسلة)
d/dx (aˣ) = aˣ·ln a عندما a > 0 (a ≠ 1)
d/dx (a^u) = a^u·ln a·u′

لماذا e؟

مشتقة aˣ هي aˣ·lim (aʰ − 1)/h. وهذه النهاية الأخيرة تساوي ln a. وعُرِّف e بأنه العدد الذي تساوي هذه النهاية عنده 1 تماماً، فيختفي العامل الإضافي وتصبح (eˣ)′ = eˣ.

لا تستخدم قاعدة القوة هنا

في xⁿ المتغير في الأساس؛ أما في eˣ و 2ˣ فالمتغير في الأس. هما عائلتان مختلفتان بقواعد مختلفة.

لماذا يعمل هذا؟

فكّر في مال ينمو باستمرار في حساب استثماري: كلما كبر المبلغ زاد ربحه، فمعدل النمو يتناسب مع المقدار الموجود. والاقتران الذي معدل تغيره يساوي نفسه هو eˣ. إنه تأثير "كرة الثلج": كلما كبرت كرة الثلج نمت أسرع.

أمثلة محلولة

مثال 1: قاعدة السلسلة. f(x) = e^(3x²): الداخلي 3x² ومشتقته 6x، إذن f′(x) = 6x·e^(3x²).
مثال 2: أساس غير e. f(x) = 2ˣ: f′(x) = 2ˣ ln 2.
g(x) = 3^(x² + 1): g′(x) = 3^(x² + 1)·ln 3·2x.
مثال 3: قسمة وتقييم. f(x) = eˣ/(1 + eˣ).
f′(x) = (eˣ(1 + eˣ) − eˣ·eˣ)/(1 + eˣ)² = (eˣ + e²ˣ − e²ˣ)/(1 + eˣ)² = eˣ/(1 + eˣ)².
عند x = 0: f′(0) = 1/(1 + 1)² = 1/4.
مثال 4: ضرب. f(x) = x²e^(−x): f′ = 2x e^(−x) + x²·(−e^(−x)) = e^(−x)(2x − x²) = x(2 − x)e^(−x). وهي تساوي صفراً عند x = 0 و x = 2، فالمماس أفقي عند هاتين النقطتين.

أخطاء شائعة

⚠️ 1) معاملة eˣ بقاعدة القوة: (eˣ)′ ≠ x·eˣ⁻¹. 2) نسيان العامل ln a للأسس غير e. 3) نسيان عامل السلسلة: (e^(2x))′ = 2e^(2x). 4) كتابة مشتقة e^(x²) على أنها e^(x²) (ينقص 2x). 5) الخلط بين e^(−x) و −e^x؛ الإشارة تأتي من مشتقة الداخلي −1.

ركن الاختبار

يأتي هذا البند بوصف Q16 · ص 194 (29-30) اختيار من متعدد. المهام المعتادة: اشتق اقتراناً فيه eˣ أو aˣ (عادةً بالسلسلة أو الضرب/القسمة)، أو احسب f′ عند نقطة مثل 0 (وتذكّر أن e⁰ = 1). وللتحقق السريع عوّض x = 0؛ فكثير من الخيارات الخاطئة يسقط عندها.

ملخص سريع

  • (eˣ)′ = eˣ؛ (e^u)′ = e^u u′.
  • (aˣ)′ = aˣ ln a؛ (a^u)′ = a^u ln a·u′.
  • قاعدة القوة لا تنطبق عندما يكون x في الأس.
  • e⁰ = 1 و ln e = 1 تفيدان في التقييم.

اختبر نفسك: أسئلة على مشتقات الدوال الأسية

قيمة x التي يكون عندها مماس منحنى f(x) = xe−2x أفقياً:

✅ الجواب: x = 1/2

f′ = e^(−2x)(1 − 2x) = 0 ⇐ x = 1/2.

قيم x التي يكون عندها مماس منحنى f(x) = x²e−2x أفقياً:

✅ الجواب: x = 0 أو x = 1

f′ = 2xe^(−2x)(1 − x) = 0.

قيم x التي يكون عندها مماس منحنى f(x) = x²e−3x أفقياً:

✅ الجواب: x = 0 أو x = 2/3

f′ = xe^(−3x)(2 − 3x) = 0، ولا نقسم على x.

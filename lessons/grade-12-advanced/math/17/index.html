نتذكر: الدوال التي تبدأ بحرف c (cos, cot, csc) مشتقاتها سالبة. وتُشتق هذه القواعد من lim sin h/h = 1.

ضرب: f(x) = x² cos x ⇐ f′ = 2x cos x − x² sin x
سلسلة: f(x) = sin(3x²) ⇐ f′ = 6x cos(3x²)
قوة + سلسلة: f(x) = cos³(2x) ⇐ f′ = 3cos²(2x)·(−sin 2x)·2 = −6cos²(2x) sin 2x
قسمة: f(x) = sin x/(1 + cos x)
f′ = (cos x(1 + cos x) + sin²x)/(1 + cos x)² = (1 + cos x)/(1 + cos x)² = 1/(1 + cos x)
مماس y = sin x عند x = π: الميل cos π = −1 والنقطة (π, 0) ⇐ y = −x + π.
⚠️ الزوايا بالراديان دائماً. و sin²x + cos²x = 1 تفيد في التبسيط. و cos³(2x) تعني (cos 2x)³.

الفكرة بالتفصيل

مشتقات الاقترانات المثلثية الستة (x بالـراديان) هي:

حيلة للحفظ: كل الاقترانات التي تبدأ بـ "co" (cos و cot و csc) تحمل إشارة سالبة في مشتقاتها. وعندما لا تكون الزاوية x فقط تضيف قاعدة السلسلة العامل u′: (sin u)′ = cos u·u′.

من أين تأتي؟

تأتي من lim sin h/h = 1 و lim (1 − cos h)/h = 0 مع قانون جمع الزوايا sin(x + h) = sin x cos h + cos x sin h. ثم تأتي tan و cot و sec و csc من قاعدة القسمة، مثلاً tan x = sin x / cos x يعطي (cos²x + sin²x)/cos²x = 1/cos²x = sec²x.

لماذا يعمل هذا؟

تخيّل موجة الجيب: عند x = 0 تصعد بميل 1، وعند قمتها (x = π/2) يكون الميل 0، ثم تهبط بميل −1. وموجة جيب التمام لها القيم نفسها (1 ثم 0 ثم −1)، فميل الجيب هو جيب التمام. الجيب وجيب التمام كعقرب ساعة وظلّه، كل منهما "خطوة" قبل الآخر.

أمثلة محلولة

مثال 1: ضرب. y = x² sin x: y′ = 2x sin x + x² cos x.
مثال 2: قسمة مع تبسيط. y = sin x/(1 + cos x).
y′ = (cos x(1 + cos x) − sin x(−sin x))/(1 + cos x)² = (cos x + cos²x + sin²x)/(1 + cos x)² = (cos x + 1)/(1 + cos x)² = 1/(1 + cos x).
مثال 3: قاعدة السلسلة. y = sin(3x²): y′ = cos(3x²)·6x = 6x cos(3x²).
y = sec(2x): y′ = 2 sec(2x) tan(2x).
y = tan²x = (tan x)²: y′ = 2 tan x·sec²x.
مثال 4: معادلة المماس (نمط المقالي). أوجد المماس لـ y = x cos x عند x = π.
y(π) = π·cos π = −π.
y′ = cos x − x sin x؛ عند π: −1 − π·0 = −1.
المماس: y + π = −1(x − π) ⇒ y = −x.

أخطاء شائعة

⚠️ 1) أخطاء الإشارة: مشتقة cos x هي −sin x. 2) نسيان عامل السلسلة: (sin 3x)′ = 3cos 3x وليس cos 3x. 3) كتابة (sin²x)′ = cos²x؛ الصحيح 2 sin x cos x. 4) ترك الآلة الحاسبة على الدرجات عند التقييم. 5) الخلط بين sec² x و sec x tan x.

ركن الاختبار

يأتي هذا البند بوصف Q15 · ص 184 (9-18) (اختيار من متعدد) و Q24 مقالي · ص 184 (3-8). في المقالي أظهر: القاعدة المستخدمة (ضرب أو قسمة أو سلسلة)، والمشتقة، والتبسيط (استخدم متطابقات مثل sin²x + cos²x = 1)، وإن طُلب فالتقييم عند النقطة أو المماس. احتفظ بالقيم الدقيقة (π و √2/2) ما لم يُطلب العشري. ويمكن للتحقق العددي بالآلة (راديان) أن يؤكد جوابك.

ملخص سريع

  • (sin)′ = cos؛ (cos)′ = −sin؛ (tan)′ = sec²؛ (cot)′ = −csc²؛ (sec)′ = sec tan؛ (csc)′ = −csc cot.
  • اقترانات "co" تحمل إشارة سالبة.
  • مع اقتران داخلي اضرب في u′ (قاعدة السلسلة).
  • راديان فقط.

النهايات اللانهائية والنهايات عند اللانهاية

📈 الرياضيات (التفاضل والتكامل)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q7 · ص 106 (9-14)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
النهاية اللانهائية (infinite limit): limx→a f(x) = ±∞ عندما يقترب المقام من 0 والبسط لا. نحدد الإشارة بتجربة عدد قريب من a.
مثال: limx→2⁺ (x + 1)/(x − 2) = +∞ و limx→2⁻ = −∞.
النهاية عند اللانهاية (limit at infinity) للدالة النسبية: نقسم على أعلى قوة لـ x في المقام.
• درجة البسط < درجة المقام ⇐ 0
• الدرجتان متساويتان ⇐ نسبة المعاملين الرئيسيين
• درجة البسط > درجة المقام ⇐ ∞ أو −∞
limx→∞ (x² + 3x − 2)/(3x² + 4x − 1) = 1/3
limx→∞ (2x + 3)/(x² + 1) = 0
مع الجذور: limx→−∞ (2x − 1)/√(x² + 1). بما أن √(x²) = |x| = −x عندما x < 0 فالنهاية = 2/(−1) = −2.
المرافق: limx→∞ (√(x² + 4x) − x) = lim 4x/(√(x² + 4x) + x) = 4/2 = 2.
نهايات مفيدة: limx→∞ e^(−x) = 0، limx→−∞ eˣ = 0، limx→∞ ln x = ∞، limx→∞ sin x / x = 0 (بالشطيرة)، أما limx→∞ sin x فغير موجودة.
⚠️ عند x → −∞ تذكّر أن √(x²) = −x، وهذا يغيّر الإشارة.

الفكرة بالتفصيل

يتناول هذا الدرس حالتين مختلفتين يسهل الخلط بينهما.

أ) النهايات اللانهائية (infinite limits): x تتجه إلى عدد و y تتجه إلى ∞

إذا اقترب المقام من 0 عندما x → a بينما يقترب البسط من عدد غير صفري فإن |f(x)| يكبر بلا حدود. نكتب limx→a f(x) = +∞ أو −∞. (النهاية "غير موجودة" بالمعنى الدقيق، لكن ∞ تصف كيف لا توجد.) ولتحديد الإشارة نجرّب عدداً قريباً قليلاً من a من اليمين أو اليسار وننظر إلى إشارتي البسط والمقام. قد تختلف الإشارة في الجهتين، وعندها تكون النهاية من الجهتين DNE. تسمى هذه النقطة خط تقارب رأسياً (vertical asymptote).

ب) النهايات عند اللانهاية (limits at infinity): x تتجه إلى ∞ و y تتجه إلى عدد

نسأل ماذا يحدث لـ f(x) عندما تصبح x ضخمة، x → ∞ أو x → −∞. في الدالة النسبية نقسم كل حد على أعلى قوة لـ x في المقام. الحدود مثل 1/x و 1/x² تتجه إلى 0. فنحصل على ثلاث حالات:

الدرجتانالنهاية عند ±∞
درجة البسط < درجة المقام0
متساويتاننسبة المعاملين الرئيسيين
درجة البسط > درجة المقام±∞ (لا نهاية منتهية)

الجذور والدوال الأسية

تذكّر أن √(x²) = |x|. عندما x → +∞ تساوي x، وعندما x → −∞ تساوي −x. وكذلك: e^(−x) → 0 عندما x → ∞، و eˣ → 0 عندما x → −∞، و ln x → ∞ عندما x → ∞، و sin x / x → 0 (بنظرية الشطيرة).

لماذا يعمل هذا؟

عندما تكون x ضخمة تسيطر أعلى قوة. في 3x² + 100x عند x = 1,000,000 يكون الحد 3x² يساوي 3 تريليونات بينما 100x لا تتجاوز 100 مليون. لذلك لا تهم إلا الحدود الرئيسية، وهذا سبب مقارنة المعاملات الرئيسية. أما النهاية اللانهائية فتأمّل 1/0.0001 = 10,000: القسمة على عدد موجب أصغر فأصغر تعطي ناتجاً أكبر فأكبر.

أمثلة محلولة

مثال 1: نهاية لانهائية مع الإشارات. limx→3⁺ (x + 1)/(x − 3) و limx→3⁻.
البسط قرب 3 يساوي 4 (موجب). عندما x أكبر قليلاً من 3 يكون x − 3 عدداً موجباً صغيراً فالناتج +∞. وعندما x أصغر قليلاً من 3 يكون x − 3 عدداً سالباً صغيراً فالناتج −∞. النهاية من الجهتين DNE، و x = 3 خط تقارب رأسي.
مثال 2: درجتان متساويتان. limx→∞ (3x² − 2x)/(5x² + 1).
نقسم على x²: (3 − 2/x)/(5 + 1/x²) → 3/5.
مثال 3: جذر عندما x → −∞. limx→−∞ 3x/√(x² + 4).
نقسم على |x| = −x (لأن x < 0): يصبح المقام √(1 + 4/x²) → 1 ويصبح البسط 3x/(−x) = −3. النهاية −3.
مثال 4: المرافق. limx→∞ (√(x² + 6x) − x) من الصيغة ∞ − ∞. نضرب في المرافق: 6x/(√(x² + 6x) + x). نقسم على x: 6/(√(1 + 6/x) + 1) → 6/2 = 3.

أخطاء شائعة

⚠️ 1) نسيان أن √(x²) = −x عندما تكون x سالبة. 2) كتابة "= ∞" لنهاية من الجهتين نهايتاها من جانب واحد +∞ و −∞؛ هذه DNE. 3) اعتبار ∞ − ∞ يساوي 0. 4) القسمة على القوة الخطأ: اقسم على أعلى قوة في المقام (مع مراعاة الجذور). 5) القول إن lim sin x عندما x → ∞ تساوي 0؛ هي غير موجودة.

ركن الاختبار

يأتي هذا البند بوصف Q7 · ص 106 (9-14) (اختيار من متعدد). حدّد أولاً: هل x تتجه إلى عدد أم إلى ما لا نهاية؟ إن كانت إلى عدد فابحث عن مقام صفري وافحص الإشارة في كل جهة. وإن كانت إلى ما لا نهاية فقارن الدرجات. وإذا وُجد جذر فانتبه لإشارة −∞. من فخاخ الخيارات: ±∞ و 0 ونسبة المعاملات والإشارة الخاطئة. وانتهِ بفحص سريع بتعويض عدد كبير مثل x = 1000 أو x = −1000.

ملخص سريع

  • النهاية اللانهائية: مقام صفري وبسط غير صفري؛ حدّد الإشارة من كل جهة.
  • النهاية عند اللانهاية للدالة النسبية: قارن الدرجات (0 أو نسبة المعاملين الرئيسيين أو ±∞).
  • √(x²) = |x| وتساوي −x عندما x < 0.
  • المرافق لصيغ ∞ − ∞ ذات الجذور.
  • e^(−x) → 0 و ln x → ∞ و sin x / x → 0 عندما x → ∞.

نظرية رول

📈 الرياضيات (التفاضل والتكامل)🎓 الصف الثاني عشر متقدم📌 هيكل الامتحان: Q20 · نظرية 10.1 ص 213

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
نظرية رول (Rolle's Theorem): إذا كانت f
1) متصلة على الفترة المغلقة [a, b]،
2) قابلة للاشتقاق على الفترة المفتوحة (a, b)،
3) f(a) = f(b)،
فإنه يوجد عدد واحد على الأقل c ∈ (a, b) بحيث f′(c) = 0 (مماس أفقي).
f(x) = x² − 4x على [0, 4]: كثيرة حدود، f(0) = f(4) = 0، f′(c) = 2c − 4 = 0 ⇐ c = 2.
f(x) = x³ − x على [−1, 1]: f(−1) = f(1) = 0، 3c² − 1 = 0 ⇐ c = ±1/√3 (كلاهما في الفترة).
f(x) = sin x على [0, π]: cos c = 0 ⇐ c = π/2.
الدالةلماذا لا تنطبق؟
|x| على [−1, 1]غير قابلة للاشتقاق عند 0
1/x² على [−1, 1]غير متصلة عند 0
x² − 2x على [0, 3]f(0) = 0 ≠ f(3) = 3
⚠️ النظرية تضمن وجود c ولا تقول كم عددها، وإذا لم تتحقق الشروط فقد توجد c وقد لا توجد. لاحظ: الاتصال على المغلقة والاشتقاق على المفتوحة.

الفكرة بالتفصيل

تقول نظرية رول (Rolle's Theorem): إذا بدأ مسار أملس وانتهى عند الارتفاع نفسه فلا بد من نقطة بينهما مماسها أفقي.

نظرية رول (نظرية 10.1): إذا كانت f
1) متصلة على الفترة المغلقة [a, b]،
2) قابلة للاشتقاق على الفترة المفتوحة (a, b)،
3) f(a) = f(b).
فيوجد عدد واحد على الأقل c في (a, b) بحيث f′(c) = 0.

كيف نطبّقها؟

  1. تحقق من الشروط الثلاثة (اذكر كلاً منها).
  2. احسب f′(x) وحلّ f′(x) = 0.
  3. اختر الحل أو الحلول التي تقع داخل (a, b).

إذا اختلّ أي شرط فلا تعطي النظرية معلومة؛ قد يتحقق الاستنتاج أحياناً لكن لا يمكن ضمانه.

لماذا يعمل هذا؟

تخيّل أنك تسير فوق تلة وتعود إلى ارتفاع البداية نفسه، أو كرة تُقذف إلى الأعلى وتُلتقط عند الارتفاع نفسه: عند القمة تتوقف عن الصعود وتبدأ بالهبوط وتكون السرعة الرأسية صفراً بالضبط. إذا بدأت دالة متصلة وانتهت بالقيمة نفسها فإما أن تبقى ثابتة (مشتقتها 0 في كل مكان) أو تصعد أو تهبط في مكان ما، وعندها لا بد من نقطة أعلى أو أدنى في الداخل مماسها أفقي. وهذه القمة أو القاع هو حيث f′ = 0.

أمثلة محلولة

مثال 1: تحقق وأوجد c. f(x) = x² − 4x + 3 على [1, 3].
f كثيرة حدود فهي متصلة على [1, 3] وقابلة للاشتقاق على (1, 3).
f(1) = 1 − 4 + 3 = 0 و f(3) = 9 − 12 + 3 = 0 فـ f(1) = f(3).
الشروط متحققة. f′(x) = 2x − 4 = 0 ⇒ x = 2 و 2 في (1, 3). إذن c = 2.
مثال 2: قيمتان لـ c. f(x) = x³ − 3x على [−√3, √3].
f(√3) = 3√3 − 3√3 = 0 و f(−√3) = −3√3 + 3√3 = 0 ✓.
f′(x) = 3x² − 3 = 0 ⇒ x = ±1. كلتاهما داخل (−√3, √3) ≈ (−1.73, 1.73). إذن c = 1 و c = −1 (رول تضمن واحدة على الأقل).
مثال 3: مثلثي. f(x) = sin x على [0, π]: f(0) = f(π) = 0. f′ = cos x = 0 ⇒ c = π/2.
مثال 4: النظرية لا تنطبق. f(x) = |x| على [−1, 1]: f(−1) = f(1) = 1 و f متصلة، لكنها غير قابلة للاشتقاق عند 0 و f′ لا تساوي 0 أبداً. الشرط 2 مختل. حالة أخرى: f(x) = x² على [0, 2] فيها f(0) = 0 ≠ f(2) = 4 فالشرط 3 مختل.
مثال 5: استخدام رول. أثبت أن للمعادلة x³ + x − 1 = 0 جذراً حقيقياً واحداً فقط.
الوجود: f(0) = −1 و f(1) = 1 فحسب IVT يوجد جذر. الوحدانية: افترض جذرين a < b فـ f(a) = f(b) = 0. حسب رول يوجد c بحيث f′(c) = 0، لكن f′(x) = 3x² + 1 > 0 دائماً. تناقض، فالجذر وحيد.

أخطاء شائعة

⚠️ 1) عدم التحقق من الشروط الثلاثة جميعاً، وخصوصاً f(a) = f(b). 2) إعطاء قيمة c خارج الفترة المفتوحة (a, b). 3) نسيان ذكر الاتصال والقابلية للاشتقاق، وهما شرطان منفصلان. 4) الاعتقاد أن النظرية تحدد عدد قيم c؛ هي تضمن واحدة على الأقل فقط. 5) تطبيقها على |x| أو على اقترانات فيها انقطاع داخل الفترة. 6) الخلط بين رول (f′(c) = 0) ونظرية القيمة المتوسطة MVT (f′(c) = الميل المتوسط).

ركن الاختبار

يأتي هذا البند بوصف Q20 · نظرية 10.1 ص 213 اختيار من متعدد. الصور الشائعة: "أوجد قيمة (قيم) c التي تضمنها نظرية رول" أو "أي اقتران يحقق نظرية رول على الفترة؟". في الصورة الثانية اختبر كل خيار: الاتصال، والقابلية للاشتقاق، وتساوي الطرفين، واستبعد ما فيه ركن حاد أو ثقب أو طرفان غير متساويين. وفي الأولى حلّ f′(x) = 0 واحتفظ بالحلول داخل الفترة فقط.

ملخص سريع

  • الشروط: متصلة على [a, b]، قابلة للاشتقاق على (a, b)، f(a) = f(b).
  • النتيجة: يوجد c في (a, b) بحيث f′(c) = 0.
  • حلّ f′(x) = 0 واحتفظ بـ c داخل الفترة المفتوحة.
  • إذا اختلّ شرط فالنظرية لا تنطبق.

اختبر نفسك: أسئلة على نظرية رول

فرضيات نظرية رول للدالة f على [a, b]:

✅ الجواب: f متصلة على [a, b] وقابلة للاشتقاق على (a, b) و f(a) = f(b)

الشروط الثلاثة: اتصال على المغلقة، اشتقاق على المفتوحة، تساوي القيمتين عند الطرفين.

إذا تحققت فرضيات نظرية رول على [a, b] فإنه يوجد c في (a, b) بحيث:

✅ الجواب: f′(c) = 0

نتيجة رول: مماس أفقي عند نقطة داخلية واحدة على الأقل.

قيمة c التي تحققها نظرية رول للدالة f(x) = x² − 4x على [0, 4]:

✅ الجواب: 2

f(0) = f(4) = 0 و f′(c) = 2c − 4 = 0.

Control systems

Open-loopClosed-loop (feedback)
No feedback; the controller sends a command and does not check the resultSensors feed back the actual result; the controller compares it with the target and corrects the error
Example: run a motor for 2 secondsExample: a servo holding an exact angle; a rover keeping a straight heading using a gyro
Closed-loop control: input (target) → controller → actuator → output → sensor → feedback back to the controller. It is more accurate and can correct disturbances.

Actuators (convert energy into motion)

TypeKey featureTypical use
DC motorContinuous rotation, speed controlled by voltage/PWMDriving wheels
Servo motorMoves to a precise angle using built-in feedbackSteering, robot arm joints
Stepper motorRotates in fixed small steps; precise positioning3D printers, precise mechanisms
Linear actuatorStraight-line push/pull motionLifting mechanisms
Hydraulic / pneumaticPressurised liquid / air; hydraulic gives large forcesHeavy lifting, grippers

Structure: must be strong, stiff and light; common materials are aluminium alloys, composites and plastics.

⚠️ A servo uses closed-loop control internally; a simple DC motor run for a fixed time is open-loop.

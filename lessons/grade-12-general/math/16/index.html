حل معادلات كثيرات الحدود بالتحليل

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q15 · ص 138 (تمارين 34، 35، 44، 47)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
النمطالتحليل
مجموع مكعبينa³ + b³ = (a + b)(a² − ab + b²)
فرق مكعبينa³ − b³ = (a − b)(a² + ab + b²)
الصيغة التربيعيةax⁴ + bx² + c: نضع u = x²
مجموع مكعبين: x³ + 216 = 0 ⇒ (x + 6)(x² − 6x + 36) = 0
x = −6 أو x = (6 ± √(36 − 144))/2 = 3 ± 3i√3
الصيغة التربيعية: 4x⁴ − 14x² + 12 = 0 ⇒ 2(2x² − 3)(x² − 2) = 0
x² = 2 ⇒ x = ±√2؛ x² = 3/2 ⇒ x = ±√6/2
⚠️ في مجموع المكعبين الإشارة الوسطى في القوس الثاني سالبة: a² − ab + b². ولا تنسَ الجذور المركبة: معادلة من الدرجة 3 لها 3 جذور، ومن الدرجة 4 لها 4 جذور.

أمثلة محلولة

1) 64x³ + 1 = 0: a = 4x, b = 1 ⇒ (4x + 1)(16x² − 4x + 1) = 0
x = −1/4 أو x = (4 ± √(16 − 64))/32 = (4 ± 4i√3)/32 = (1 ± i√3)/8
2) 24x⁴ + 14x² − 3 = 0: u = x² ⇒ 24u² + 14u − 3 = 0 ⇒ u = (−14 ± 22)/48 ⇒ u = 1/6 أو u = −3/4
x = ±√6/6 أو x = ±i√3/2
3) x⁴ − 5x² + 4 = 0 ⇒ (x² − 1)(x² − 4) = 0 ⇒ x = ±1, ±2.
4) x³ − 9x = 0 ⇒ x(x − 3)(x + 3) = 0 ⇒ x = 0, ±3.

تبسيط الجذور

√(1/6) = 1/√6 = √6/6، √(3/2) = √6/2، √(−3/4) = i√3/2.

أخطاء شائعة

⚠️ 1) (x + 6)(x² + 6x + 36) خطأ في الإشارة. 2) نسيان ± عند x² = 2. 3) نسيان الحل x = 0 عند إخراج x عاملاً مشتركاً. 4) إهمال الجذور التخيلية عندما يكون u سالباً.

اختبر نفسك: أسئلة على حل معادلات كثيرات الحدود بالتحليل

حل المعادلة x³ + 216 = 0

✅ الجواب: −6, 3 ± 3i√3

(x + 6)(x² − 6x + 36) = 0 ⇒ x = (6 ± √−108)/2 = 3 ± 3i√3.

حل المعادلة 64x³ + 1 = 0

✅ الجواب: −1/4, (1 ± i√3)/8

(4x + 1)(16x² − 4x + 1) = 0 ⇒ x = (4 ± 4i√3)/32 = (1 ± i√3)/8.

حل المعادلة 4x⁴ − 14x² + 12 = 0

✅ الجواب: ±√2, ±√6/2

2(2x² − 3)(x² − 2) = 0 ⇒ x² = 2 أو x² = 3/2 ⇒ ±√2، ±√6/2.

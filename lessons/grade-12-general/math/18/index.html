حل المعادلات الأسية (مقالي)

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q24 مقالي · ص 218 (تمارين 9، 10، 12، 13)

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
خاصية التساوي: إذا كان bˣ = bʸ فإن x = y (حيث b > 0, b ≠ 1).
الخطوات: 1) اكتب الطرفين كقوى لنفس الأساس. 2) استخدم (bᵐ)ⁿ = bᵐⁿ. 3) ساوِ الأسس وحل المعادلة الخطية.

8^(4x + 2) = 64 ⇒ 8^(4x + 2) = 8² ⇒ 4x + 2 = 2 ⇒ x = 0
5^(x − 6) = 125 ⇒ 5^(x − 6) = 5³ ⇒ x − 6 = 3 ⇒ x = 9
⚠️ عند رفع قوة لقوة نضرب الأس في كل حدود الأس: (4⁴)^(b + 2) = 4^(4b + 8) وليس 4^(4b + 2).

أمثلة محلولة (من الهيكل)

1) 256^(b + 2) = 4^(2 − 2b)
(4⁴)^(b + 2) = 4^(2 − 2b)
4^(4b + 8) = 4^(2 − 2b)
4b + 8 = 2 − 2b ⇒ 6b = −6 ⇒ b = −1
2) 9^(3c + 1) = 27^(3c − 1)
(3²)^(3c + 1) = (3³)^(3c − 1)
3^(6c + 2) = 3^(9c − 3)
6c + 2 = 9c − 3 ⇒ 5 = 3c ⇒ c = 5/3
3) 2^(x + 3) = 1/16 = 2⁻⁴ ⇒ x + 3 = −4 ⇒ x = −7
4) 16ˣ = 8^(x + 1) ⇒ 2^(4x) = 2^(3x + 3) ⇒ x = 3

التحقق

عوّض الحل: b = −1: 256¹ = 256 و 4^(2 + 2) = 4⁴ = 256 ✓.

أخطاء شائعة

⚠️ 1) مساواة الأسس قبل توحيد الأساس (مثلاً 4b + 2 = 2 − 2b مع أساسين مختلفين). 2) نسيان توزيع الضرب على كل حد في الأس. 3) الخطأ في الكسور: 1/16 = 2⁻⁴ وليس 2⁴. 4) قسمة الأساسات: 64/8 ≠ طريقة للحل.

اختبر نفسك: أسئلة على حل المعادلات الأسية (مقالي)

حل المعادلة 8^(4x + 2) = 64

✅ الجواب: x = 0

64 = 8² ⇒ 4x + 2 = 2 ⇒ x = 0.

حل المعادلة 5^(x − 6) = 125

✅ الجواب: x = 9

125 = 5³ ⇒ x − 6 = 3 ⇒ x = 9.

حل المعادلة 256^(b + 2) = 4^(2 − 2b)

✅ الجواب: b = −1

256 = 4⁴ ⇒ 4b + 8 = 2 − 2b ⇒ 6b = −6 ⇒ b = −1.

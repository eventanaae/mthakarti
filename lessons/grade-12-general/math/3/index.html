حل المعادلات التربيعية بالتمثيل البياني

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q3 · الدرس 1-2 · ص 17–18

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

حلول المعادلة ax² + bx + c = 0 (وتسمى جذوراً) هي أصفار الدالة المرتبطة f(x) = ax² + bx + c، أي الإحداثيات x لنقاط تقاطع القطع مع المحور x.

شكل التقاطععدد الحلول الحقيقية
يقطع المحور x في نقطتينحلان حقيقيان
يمس المحور x في نقطة واحدة (الرأس على المحور)حل حقيقي واحد مكرر
لا يقطع المحور xلا يوجد حل حقيقي
الخطوات: 1) اجعل الطرف الأيمن صفراً. 2) مثّل الدالة المرتبطة (أو استخدم الحاسبة/جدولاً). 3) اقرأ نقاط التقاطع مع المحور x.
x² − 2x − 8 = 0: القطع يقطع المحور x عند x = −2 و x = 4. تحقق: (−2)² − 2(−2) − 8 = 0 ✓.
x² − 6x = −9 ⇒ x² − 6x + 9 = 0. الرأس (3, 0) على المحور ⇒ حل واحد x = 3.
⚠️ لا تقرأ المقطع y على أنه حل! الحلول على المحور x. ولا تنسَ نقل الحدود ليصبح الطرف الأيمن صفراً قبل الرسم.

لماذا؟

على المحور x تكون y = 0، والمعادلة تسأل: متى تساوي الدالة صفراً؟ لذلك كل نقطة تقاطع مع المحور x تعطي حلاً.

عندما لا يكون الحل عدداً صحيحاً

إذا وقع التقاطع بين عددين صحيحين، نقول إن الجذر "بين" هذين العددين، أو نقدّره. استخدم جدول قيم: أين تتغير إشارة y؟ مثال x² − 3 = 0: f(1) = −2، f(2) = 1 ⇒ جذر بين 1 و 2 (هو √3 ≈ 1.73)، وبالتماثل جذر آخر بين −2 و −1.

أمثلة محلولة

1) x² − x − 2 = 0: التقاطع عند x = −1 و x = 2.
2) x² + 2x − 15 = 0: المحور x = −1، والتقاطعان عند x = −5, x = 3 (متماثلان حول −1).
3) x² + 4 = 0: القطع رأسه (0, 4) ويفتح لأعلى فلا يقطع المحور x ⇒ لا يوجد حل حقيقي.

أخطاء شائعة

⚠️ 1) الرسم قبل نقل الحدود. 2) قراءة إحداثي y بدل x. 3) اعتبار الحل المكرر حلين مختلفين. 4) نسيان أن الحلين متماثلان حول محور التماثل؛ استخدم ذلك للتحقق.

ركن الاختبار

Q3: تُعطى المعادلة مع تمثيلها البياني وتختار الحلول. اقرأ نقاط التقاطع ثم تحقق بالتعويض في المعادلة الأصلية.

اختبر نفسك: أسئلة على حل المعادلات التربيعية بالتمثيل البياني

حلّ x² − 2x − 8 = 0 بالتمثيل البياني.

✅ الجواب: x = −2, x = 4

القطع يقطع المحور x عند −2 و 4. تحقق: 16 − 8 − 8 = 0.

حلّ المعادلة x² − 6x = −9 بالتمثيل البياني.

✅ الجواب: x = 3

x² − 6x + 9 = 0 والرأس (3, 0) يمس المحور ⇒ حل واحد مكرر x = 3.

استخدم التمثيل البياني للمعادلة x² − x − 2 = 0 لتحديد حلولها.

✅ الجواب: x = −1, x = 2

(x − 2)(x + 1) = 0 والقطع يقطع المحور عند −1 و 2.

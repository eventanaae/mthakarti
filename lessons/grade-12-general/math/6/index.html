حل المعادلات التربيعية بالتحليل إلى العوامل

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q4 · الدرس 1-4 · مثال 4 · ص 36

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
خاصية الضرب الصفري: إذا كان pq = 0 فإن p = 0 أو q = 0.
نكتب المعادلة على صورة (x − p)(x − q) = 0 فتكون الحلول p و q.
النوعالطريقةمثال
x² + bx + cعددان حاصل ضربهما c ومجموعهما bx² + 9x + 20 = (x + 4)(x + 5)
ax² + bx + cعددان حاصل ضربهما ac ومجموعهما b ثم التجميع6y² − 23y + 20 = (3y − 4)(2y − 5)
عامل مشتركنخرج العامل الأكبر3x² − 12x = 3x(x − 4)
فرق مربعينa² − b² = (a − b)(a + b)x² − 16 = (x − 4)(x + 4)
6y² − 23y + 20 = 0: ac = 120، عددان مجموعهما −23 وضربهما 120: −8 و −15.
6y² − 8y − 15y + 20 = 2y(3y − 4) − 5(3y − 4) = (3y − 4)(2y − 5)
y = 4/3 أو y = 5/2
⚠️ الحل من العامل (x + 4) هو x = −4 (عكس الإشارة). لا تقسم على x لأنك تفقد الحل x = 0.

لماذا نجعل الطرف صفراً؟

خاصية الضرب الصفري تعمل فقط مع الصفر. (x − 2)(x − 3) = 6 لا تعني أن x − 2 = 6! لذلك ننقل كل الحدود أولاً.

أمثلة محلولة

1) x² + 9x + 20 = 0: 4 × 5 = 20 و 4 + 5 = 9 ⇒ (x + 4)(x + 5) = 0 ⇒ x = −4, x = −5.
2) x² − 5x − 14 = 0: −7 × 2 = −14 و −7 + 2 = −5 ⇒ (x − 7)(x + 2) ⇒ x = 7, x = −2.
3) 2x² + 7x + 3 = 0: ac = 6، العددان 1 و 6 ⇒ (2x + 1)(x + 3) = 0 ⇒ x = −1/2, x = −3.
4) x² − 10x + 25 = 0 ⇒ (x − 5)² = 0 ⇒ حل مكرر x = 5.
5) العكس: معادلة جذراها 3 و −2: (x − 3)(x + 2) = x² − x − 6 = 0.

أخطاء شائعة

⚠️ 1) أخذ إشارة العامل كما هي. 2) في (3y − 4) الحل 4/3 وليس 3/4. 3) قسمة الطرفين على x. 4) نسيان العامل المشترك قبل التحليل.

ركن الاختبار

Q4: اختيار من متعدد "حل بالتحليل". حيلة سريعة: عوّض كل خيار في المعادلة، أو تأكد أن مجموع الجذرين = −b/a وحاصل ضربهما = c/a. للمعادلة 6y² − 23y + 20: المجموع 23/6 = 4/3 + 5/2 ✓.

اختبر نفسك: أسئلة على حل المعادلات التربيعية بالتحليل إلى العوامل

حل المعادلة بالتحليل إلى العوامل: 6y² − 23y + 20 = 0

✅ الجواب: y = 4/3, y = 5/2

(3y − 4)(2y − 5) = 0 ⇒ y = 4/3 أو 5/2.

حل المعادلة بالتحليل إلى العوامل: x² + 9x + 20 = 0

✅ الجواب: x = −5, x = −4

(x + 4)(x + 5) = 0 ⇒ x = −4 أو −5.

حل المعادلة بالتحليل: x² − 5x − 14 = 0

✅ الجواب: x = 7, x = −2

(x − 7)(x + 2) = 0. تحقق: 49 − 35 − 14 = 0.

المميز: عدد الجذور ونوعها

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q7 · الدرس 1-6 · المفهوم الأساسي · ص 57

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

المميز (discriminant) هو ما تحت الجذر في القانون العام: D = b² − 4ac.

قيمة المميزعدد الجذور ونوعهاالتمثيل البياني
D > 0 ومربع كاملجذران حقيقيان نسبيانيقطع المحور x مرتين
D > 0 وليس مربعاً كاملاًجذران حقيقيان غير نسبيينيقطع المحور x مرتين
D = 0جذر حقيقي نسبي واحد مكرريمس المحور x عند الرأس
D < 0جذران مركبان (مترافقان)لا يقطع المحور x
15x² − 7x − 4 = 0: D = 49 − 4(15)(−4) = 49 + 240 = 289 = 17² ⇒ جذران حقيقيان نسبيان.
−5x² + 8x − 1 = 0: D = 64 − 4(−5)(−1) = 64 − 20 = 44 (ليس مربعاً كاملاً) ⇒ جذران حقيقيان غير نسبيين.
⚠️ اجعل الطرف الأيمن صفراً قبل تحديد c: في 3x² − 5x = 7 تكون c = −7 فالمميز 25 + 84 = 109 > 0، وإجابة عبد العزيز هي الصحيحة.

لماذا يعمل؟

في القانون العام نأخذ ±√D. إذا D موجب نحصل على قيمتين مختلفتين، وإذا صفر يختفي ± فيبقى حل واحد، وإذا سالب يظهر العدد التخيلي i. وإذا كان D مربعاً كاملاً يخرج الجذر عدداً صحيحاً فتكون الحلول نسبية (كسوراً).

أمثلة محلولة

1) x² + 22x + 121 = 0: D = 484 − 484 = 0 ⇒ جذر حقيقي نسبي واحد مكرر (هو −11).
2) 7x² − 11x + 5 = 0: D = 121 − 140 = −19 ⇒ جذران مركبان.
3) إيجاد مجهول: x² + mx + 9 = 0 لها حل وحيد ⇒ m² − 36 = 0 ⇒ m = ±6.
4) من الرسم: قطع يقطع المحور x في نقطتين ⇒ D > 0؛ يمسه عند الرأس ⇒ D = 0؛ فوقه تماماً ⇒ D < 0.

أخطاء شائعة

⚠️ 1) −4ac عندما a و c مختلفتا الإشارة تصبح موجبة (15 و −4 ⇒ +240). 2) نسيان نقل الحدود. 3) الخلط بين "نسبي" (D مربع كامل) و"غير نسبي". 4) قول "لا يوجد جذور" عندما D < 0؛ الصحيح "جذران مركبان".

ركن الاختبار

Q7: "أوجد قيمة المميز وصف عدد الجذور ونوعها". الخيار الصحيح يجب أن تكون القيمة والوصف كلاهما صحيحين؛ كثير من الخيارات فيها القيمة صحيحة والوصف خطأ.

اختبر نفسك: أسئلة على المميز: عدد الجذور ونوعها

أوجد قيمة المميز وصف عدد الجذور ونوعها: x² + 22x + 121 = 0

✅ الجواب: المميز 0، جذر حقيقي نسبي واحد مكرر

D = 22² − 4(1)(121) = 484 − 484 = 0.

أوجد قيمة المميز وصف الجذور: 7x² − 11x + 5 = 0

✅ الجواب: المميز −19، جذران مركبان

D = 121 − 4(7)(5) = 121 − 140 = −19 < 0.

أوجد قيمة المميز وصف الجذور: −5x² + 8x − 1 = 0

✅ الجواب: المميز 44، جذران حقيقيان غير نسبيين

D = 64 − 4(−5)(−1) = 64 − 20 = 44، و 44 ليس مربعاً كاملاً.

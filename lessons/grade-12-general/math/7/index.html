القانون العام لحل المعادلة التربيعية

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q6 · الدرس 1-6 · مثال 2 و 3 · ص 55

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
القانون العام: لحل ax² + bx + c = 0:
x = (−b ± √(b² − 4ac)) / (2a)
  1. اكتب المعادلة بالصيغة القياسية (الطرف الأيمن = 0).
  2. حدد a و b و c مع الإشارات.
  3. عوّض بين أقواس، خاصة القيم السالبة.
  4. بسّط ما تحت الجذر أولاً، ثم الجذر.
خطوة التعويض الصحيحة للمعادلة x² − 5x + 6 = 0 (a = 1، b = −5، c = 6):
x = (−(−5) ± √((−5)² − 4(1)(6))) / (2(1))
= (5 ± √(25 − 24))/2 = (5 ± 1)/2 ⇒ x = 3 أو x = 2
2x² + 4x − 5 = 0: x = (−4 ± √(16 + 40))/4 = (−4 ± √56)/4 = (−4 ± 2√14)/4 = (−2 ± √14)/2 ⇒ x ≈ 0.87, −2.87
⚠️ (−5)² = 25 وليس −5² = −25. والمقام 2a تحت كل البسط وليس تحت الجذر فقط. وانتبه: −4ac مع c سالبة تصبح موجبة.

من أين جاء القانون؟

هو نتيجة إكمال المربع للمعادلة العامة: نقسم على a، ننقل c/a، نضيف (b/2a)²، فنحصل على (x + b/2a)² = (b² − 4ac)/4a²، ثم نأخذ الجذر. لذلك يعمل مع أي معادلة تربيعية، حتى التي لا تتحلل.

أمثلة محلولة

1) x² − 2x − 4 = 0: x = (2 ± √(4 + 16))/2 = (2 ± 2√5)/2 = 1 ± √5.
2) حلول مركبة: x² + 2x + 5 = 0: x = (−2 ± √(4 − 20))/2 = (−2 ± 4i)/2 = −1 ± 2i.
3) 3x² + x − 2 = 0: x = (−1 ± √(1 + 24))/6 = (−1 ± 5)/6 ⇒ x = 2/3 أو x = −1.

تبسيط الجذور

√56 = √(4·14) = 2√14، ثم نقسم كل الحدود على العامل المشترك: (−4 ± 2√14)/4 = (−2 ± √14)/2.

أخطاء شائعة

⚠️ 1) استخدام b بدل −b. 2) كتابة −5² بدون أقواس. 3) القسمة على 2 بدل 2a. 4) تبسيط جزء من البسط فقط: (−4 ± 2√14)/4 ليست −1 ± 2√14.

ركن الاختبار

Q6 يسأل عن خطوة التعويض الصحيحة أو حلول معادلة بالقانون العام. قارن الخيارات في: الإشارة أمام b، الأقواس في (−5)²، والمقام 2(1).

اختبر نفسك: أسئلة على القانون العام لحل المعادلة التربيعية

في المعادلة x² − 5x + 6 = 0، أي مما يلي يمثل خطوة التعويض الصحيحة في القانون العام؟

✅ الجواب: x = (−(−5) ± √((−5)² − 4(1)(6))) / 2(1)

a = 1، b = −5، c = 6؛ نكتب −b = −(−5) و b² = (−5)² بالأقواس، والمقام 2a = 2(1).

حل المعادلة x² − 5x + 6 = 0 بالقانون العام.

✅ الجواب: x = 2 أو x = 3

x = (5 ± √1)/2 ⇒ 3 أو 2.

حل 2x² + 4x − 5 = 0 بالقانون العام.

✅ الجواب: x = (−2 ± √14)/2

x = (−4 ± √56)/4 = (−4 ± 2√14)/4 = (−2 ± √14)/2 ≈ 0.87 أو −2.87.

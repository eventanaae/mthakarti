إكمال المربع: إيجاد c لثلاثي حدود مربع كامل

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q5 · الدرس 1-3 · ص 24–25

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

ثلاثي الحدود المربع الكامل (perfect square trinomial) يكتب على شكل (x + m)². لجعل x² + bx + c مربعاً كاملاً نختار:

c = (b/2)² ثم x² + bx + (b/2)² = (x + b/2)²
x² + 4x + c: c = (4/2)² = 4 ⇒ x² + 4x + 4 = (x + 2)².
r² − 8r + c: c = (−8/2)² = 16 ⇒ (r − 4)². لاحظ أن c موجبة دائماً.
x² − 7x + c: c = (−7/2)² = 49/4 ⇒ (x − 7/2)².
العكس: x² + cx + 100 مربع كامل ⇒ (c/2)² = 100 ⇒ c/2 = ±10 ⇒ c = ±20.
⚠️ c = (b/2)² وليس b/2 ولا b². ولا تكون c سالبة أبداً. والعلامة داخل القوس هي إشارة b.

لماذا (b/2)²؟

عند فك (x + m)² = x² + 2mx + m². نقارن مع x² + bx + c: 2m = b ⇒ m = b/2، و c = m² = (b/2)². هندسياً: مربع ضلعه x مع مستطيلين عرض كل منهما b/2؛ الركن الناقص مربع مساحته (b/2)².

إذا كان معامل x² ليس 1

نقسم أولاً على المعامل. مثلاً 2x² + 12x = 2(x² + 6x) ونكمل المربع داخل القوس بإضافة 9.

أمثلة محلولة

1) x² + 10x + c ⇒ c = 25 ⇒ (x + 5)².
2) x² − 12x + c ⇒ c = 36 ⇒ (x − 6)².
3) x² + x + c ⇒ c = (1/2)² = 1/4 ⇒ (x + 1/2)².

أخطاء شائعة

⚠️ 1) أخذ نصف b بدون تربيع. 2) تربيع b بدون قسمة. 3) جعل c سالبة لأن b سالبة. 4) في الكسور: (7/2)² = 49/4 وليس 49/2.

ركن الاختبار

Q5 يطلب قيمة c التي تجعل ثلاثي الحدود مربعاً كاملاً، أو العكس (معامل x). قانون واحد: c = (b/2)².

اختبر نفسك: أسئلة على إكمال المربع: إيجاد c لثلاثي حدود مربع كامل

جد قيمة c التي تجعل x² + 4x + c ثلاثي حدود مربعاً كاملاً.

✅ الجواب: c = 4

c = (4/2)² = 4 ⇒ (x + 2)².

جد قيمة c التي تجعل r² − 8r + c ثلاثي حدود مربعاً كاملاً.

✅ الجواب: c = 16

c = (−8/2)² = (−4)² = 16 ⇒ (r − 4)².

جد قيمة موجبة لـ c تجعل x² + cx + 100 مربعاً كاملاً.

✅ الجواب: c = 20

(c/2)² = 100 ⇒ c/2 = 10 ⇒ c = 20، فيكون (x + 10)².

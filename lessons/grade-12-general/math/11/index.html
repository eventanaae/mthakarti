حل المتباينات التربيعية بمتغير واحد (مقالي)

📐 الرياضيات🎓 الصف الثاني عشر عام📌 هيكل الامتحان: هيكل Q22 مقالي · الدرس 1-8 · مثال 2 و 3 · ص 74–75

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي
  1. اجعل طرفاً صفراً: ax² + bx + c < 0 (أو >، ≤، ≥).
  2. أوجد أصفار الدالة المرتبطة (تحليل أو قانون عام): x₁ < x₂.
  3. إذا a > 0: < 0 ⇒ بين الجذرين؛ > 0 ⇒ خارج الجذرين.
  4. مع ≤ أو ≥ ندخل الجذرين في الحل.
من الهيكل: x² + 2x − 8 < 0
(x + 4)(x − 2) = 0 ⇒ x = −4, x = 2
نريد الجزء تحت المحور ⇒ {x | −4 < x < 2}
2x² + 4x − 5 ≥ 0: الأصفار (−2 ± √14)/2 ≈ −2.87, 0.87 ⇒ x ≤ −2.87 أو x ≥ 0.87.
⚠️ إذا كان a < 0 اضرب الطرفين في −1 واقلب رمز المتباينة أولاً.

طريقة جدول الإشارات (بديلة)

الجذران يقسمان خط الأعداد إلى ثلاث فترات. اختر عدداً من كل فترة وعوّضه: الإشارة ثابتة داخل الفترة.

x² − x − 2 ≥ 0: الجذران −1 و 2. نختبر x = −2: 4 + 2 − 2 = 4 ≥ 0 ✓؛ x = 0: −2 ✗؛ x = 3: 4 ✓ ⇒ x ≤ −1 أو x ≥ 2.

أمثلة أخرى

1) x² − 3x ≤ 18 ⇒ x² − 3x − 18 ≤ 0 ⇒ (x − 6)(x + 3) ≤ 0 ⇒ [−3, 6].
2) −x² + 4x + 5 ≥ 0 ⇒ نضرب في −1 ونقلب: x² − 4x − 5 ≤ 0 ⇒ (x − 5)(x + 1) ≤ 0 ⇒ −1 ≤ x ≤ 5.
3) حالات خاصة: x² + 4 < 0 لا يوجد حل (المربع لا يكون سالباً). x² − 6x + 9 ≤ 0 ⇒ (x − 3)² ≤ 0 ⇒ x = 3 فقط.

أخطاء شائعة

⚠️ 1) كتابة x < −4 و x < 2 من عاملين (خطأ منطقي). 2) نسيان قلب الرمز عند الضرب في سالب. 3) استخدام () مع ≤ بدلاً من []. 4) الحل "أو" للخارج و"بين" للداخل.

اختبر نفسك: أسئلة على حل المتباينات التربيعية بمتغير واحد (مقالي)

حل المتباينة x² + 2x − 8 < 0.

✅ الجواب: {x | −4 < x < 2}

(x + 4)(x − 2) < 0 و a > 0 ⇒ بين الجذرين، والرمز < لا يشمل الجذرين.

حل المتباينة x² − x − 2 ≥ 0.

✅ الجواب: x ≤ −1 أو x ≥ 2

الجذران −1 و 2، و ≥ 0 مع a > 0 ⇒ خارج الجذرين مع دخولهما.

حل المتباينة x² − 3x ≤ 18.

✅ الجواب: [−3, 6]

x² − 3x − 18 ≤ 0 ⇒ (x − 6)(x + 3) ≤ 0 ⇒ −3 ≤ x ≤ 6.

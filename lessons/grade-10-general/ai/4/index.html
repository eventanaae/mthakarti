How Data is Processed: Forward Propagation (الانتشار الأمامي)

🤖 الذكاء الاصطناعي والتكنولوجيا🎓 الصف العاشر عام📌 هيكل الامتحان: L01 Neural Networks and Deep Learning

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

Data processing pipeline:
INPUT (data enters) → WEIGHTS (importance) → SUM + BIAS (combine) → ACTIVATION (move forward?) → HIDDEN (learn features) → OUTPUT (prediction)

Forward propagation (الانتشار الأمامي) – every neuron performs three steps:
Step 1: Multiply each input by its corresponding weight.
Step 2: Add all weighted inputs together and include a bias: z = Σ(w·x) + b
Step 3: Apply an activation function to determine the neuron's output.
This repeats layer by layer until the final prediction is produced.

Key concepts:

  • Every connection has a weight.
  • Weights determine the importance of each input.
  • The activation function determines whether information moves forward.
  • Each hidden layer extracts increasingly complex features.
A neuron has inputs x1 = 2 and x2 = 3, weights w1 = 0.5 and w2 = 1, and bias b = 1.
z = (2 × 0.5) + (3 × 1) + 1 = 1 + 3 + 1 = 5. Then the activation function decides what the neuron passes on.
⚠️ Order matters: multiply by weights → add + bias → activation function. Information flows from input to output.

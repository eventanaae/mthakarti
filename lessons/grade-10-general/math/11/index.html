تحليل وحل ax² + bx + c

🧮 الرياضيات🎓 الصف العاشر عام📌 هيكل الامتحان: Q6 · Q25

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

طريقة التجميع: نضرب a × c، ندوّر على عددين ضربهم ac وجمعهم b، نقسم الحد الأوسط، ونحلل بالتجميع.

2x² + 7x + 3: ac = 6 ← العددان 6 , 1
2x² + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3)
حل 2x² − 5x − 3 = 0 ← (2x + 1)(x − 3) = 0 ← x = −½ أو x = 3

الفكرة بالتفصيل

عندما يكون معامل x² غير 1، أي ax² + bx + c مع a ≠ 1، لا نكتفي بالبحث عن عددين ضربهما c. نستخدم طريقة ac (التجميع):

  1. أخرج العامل المشترك الأكبر أولًا إن وجد.
  2. احسب a × c.
  3. ابحث عن عددين ضربهما ac وجمعهما b.
  4. اكتب الحد الأوسط مجموعًا لحدّين بهذين العددين.
  5. حلّل بالتجميع (خذ العامل المشترك من كل زوج) فيظهر قوس مشترك.

ليش ac؟

عند ضرب (px + q)(rx + s) يكون الحد الأوسط (ps + qr)x وحاصل ضرب هذين المعاملين ps · qr = pr · qs = a · c. فالعددان اللذان نبحث عنهما هما بالضبط ps وqr، وهما اللذان ينقسم إليهما الحد الأوسط.

أمثلة محلولة

مثال 1: 6x² + 11x + 3: ac = 18، جمعهما 11 ← 9 , 2.
6x² + 9x + 2x + 3 = 3x(2x + 3) + 1(2x + 3)
= (3x + 1)(2x + 3). تحقق بـ FOIL: 6x² + 9x + 2x + 3 ✓.
مثال 2: 3x² − 7x − 6: ac = −18، جمعهما −7 ← −9 , 2.
3x² − 9x + 2x − 6 = 3x(x − 3) + 2(x − 3) = (3x + 2)(x − 3).
مثال 3 (حل): 2x² + x − 10 = 0: ac = −20، جمعهما 1 ← 5 , −4.
2x² + 5x − 4x − 10 = x(2x + 5) − 2(2x + 5) = (x − 2)(2x + 5).
x = 2 أو 2x + 5 = 0 فـ x = −5/2. تحقق من 2: 8 + 2 − 10 = 0 ✓.
مثال 4 (عامل مشترك أولًا): 4x² + 10x + 6 = 2(2x² + 5x + 3) = 2(2x + 3)(x + 1).
⚠️ أخطاء شائعة: (1) عند أخذ عامل سالب في الزوج الثاني تنسى قلب الإشارات: −4x − 10 = −2(2x + 5). (2) إذا لم يظهر قوس مشترك فغالبًا في اختيارك العددين خطأ. (3) تنسى إخراج العامل المشترك. (4) الحل x = −1/2 من (2x + 1)، وليس x = 1/2.
🎯 ركن الامتحان (Q6 · Q25): Q6 تحليل، وQ25 حل معادلة تربيعية أمامها a ≠ 1. اكتب ac والعددين، ثم خطوة التجميع (لأنها تعطي الدرجات). في الحل أعطِ حلّين، وقد يكون أحدهما كسرًا. جرّب إدراج الجواب في المعادلة لتتأكد.

ملخص سريع

  • ضرب a × c ، جمعهما b.
  • قسّم الحد الأوسط ثم جمّع.
  • يجب أن يتكرر القوس نفسه في المجموعتين.
  • تحقق بـ FOIL.
  • في الحل: ساوِ كل عامل بالصفر.

اختبر نفسك: أسئلة على تحليل وحل ax² + bx + c

تحليل 2x² + 7x + 3:

✅ الجواب: (2x + 1)(x + 3)

ac = 6 ← 6 و 1 ← 2x(x+3) + 1(x+3)

تحليل 3x² − 10x + 8:

✅ الجواب: (3x − 4)(x − 2)

تحقق: 3x² − 6x − 4x + 8 = 3x² − 10x + 8

حلول 2x² − 5x − 3 = 0 هي:

✅ الجواب: x = 3 , x = −½

(2x + 1)(x − 3) = 0 ← 2x = −1

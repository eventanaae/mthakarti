الأسس النسبية وحل معادلاتها

🧮 الرياضيات🎓 الصف العاشر عام📌 هيكل الامتحان: Q10 · Q16

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

a^(1/n) = ⁿ√a · a^(m/n) = (ⁿ√a)ᵐ — المقام هو الجذر، والبسط هو القوة.

27^(1/3) = 3 · 16^(3/4) = (⁴√16)³ = 2³ = 8 · 25^(−1/2) = 1/5
حل 9ˣ = 27 ← 3²ˣ = 3³ ← 2x = 3 ← x = 3/2

الفكرة بالتفصيل

ماذا يعني أن يكون الأس كسرًا؟ نريد أن تبقى خواص الأسس صحيحة: a^(1/2) · a^(1/2) = a¹ = a، إذن a^(1/2) عدد مربعه a، أي √a. وبالتعميم:

  • a^(1/n) = ⁿ√a (جذر نوني).
  • a^(m/n) = (ⁿ√a)ᵐ = ⁿ√(aᵐ): المقام جذر والبسط قوة.
  • a^(−m/n) = 1 / a^(m/n).

ننصح بأخذ الجذر أولًا (لأن الأعداد تصغر) ثم القوة.

حل معادلات الأسس

النوع الأول (المجهول في الأس): نكتب الطرفين بنفس الأساس ثم نساوي الأسس. النوع الثاني (المجهول في الأساس): نرفع الطرفين إلى مقلوب الأس: x^(3/2) = 27 ← x = 27^(2/3) = 9.

أمثلة محلولة

مثال 1: 8^(2/3) = (∛8)² = 2² = 4
مثال 2: 32^(−2/5) = 1/(⁵√32)² = 1/2² = 1/4
مثال 3: 4^(x + 1) = 32 ← 2^(2x+2) = 2⁵ ← 2x + 2 = 5 ← x = 3/2. تحقق: 4^2.5 = 2⁵ = 32 ✓.
مثال 4: 5^(x − 2) = 1/125 = 5⁻³ ← x − 2 = −3 ← x = −1.
مثال 5: 27ˣ = 81 ← 3^(3x) = 3⁴ ← x = 4/3.
مثال 6: x^(3/2) = 27 ← نرفع للقوة 2/3 ← x = 27^(2/3) = (∛27)² = 9. تحقق: 9^(3/2) = (√9)³ = 27 ✓.
⚠️ أخطاء شائعة: (1) تعكس البسط والمقام: 16^(3/4) ← الجذر الرابع ثم التكعيب. (2) تهمل الإشارة السالبة للأس (مقلوب). (3) تساوي الأسس قبل توحيد الأساس. (4) تظن 4^(1/2) = 2 يعني نقسم 4 على 2 (هذا خطأ في المفهوم).
🎯 ركن الامتحان (Q10 · Q16): Q10 قيمة عدد بأس نسبي أو كتابته بصيغة جذرية، وQ16 حل معادلة أسية. اكتب خطوة توحيد الأساس واضحة، وخذ الجذر المناسب أولًا. تحقق بالتعويض إذا بقي وقت.

ملخص سريع

  • a^(m/n) = (ⁿ√a)ᵐ (المقام جذر ، البسط قوة).
  • أس سالب = مقلوب.
  • نفس الأساس ← نساوي الأسس.
  • مجهول في الأساس ← نرفع لمقلوب الأس.

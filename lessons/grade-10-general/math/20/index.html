جمع وطرح الجذور

🧮 الرياضيات🎓 الصف العاشر عام📌 هيكل الامتحان: Q13

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

نجمع الجذور المتشابهة فقط (نفس الرقم تحت الجذر)، مثل الحدود المتشابهة. أحياناً لازم نبسط أول.

5√3 + 2√3 = 7√3
√12 + √27 = 2√3 + 3√3 = 5√3
3√8 − √2 = 6√2 − √2 = 5√2

⚠️ √12 + √27 ≠ √39

الفكرة بالتفصيل

جمع الجذور مثل جمع الحدود المتشابهة تمامًا: 3√5 + 6√5 نعتبر √5 مثل «متغير» فنجمع المعاملات: (3 + 6)√5 = 9√5. وتسمى الجذور المتشابهة (like radicals) إذا كانت لها نفس العدد تحت الجذر ونفس الدليل.

أحيانًا يبدو أن الجذور مختلفة لكنها تصير متشابهة بعد التبسيط بإخراج المربعات الكاملة. لذلك الخطوة الأولى دائمًا: بسّط كل جذر، ثم اجمع أو اطرح المتشابه. والجذور غير المتشابهة تُترك كما هي.

ليش لا نجمع ما تحت الجذر؟

√9 + √16 = 3 + 4 = 7 لكن √(9 + 16) = √25 = 5. النتيجتان مختلفتان؛ إذن √a + √b ≠ √(a + b).

أمثلة محلولة

مثال 1: 7√5 − 3√5 + √5 = (7 − 3 + 1)√5 = 5√5
مثال 2: √45 + √20 = 3√5 + 2√5 = 5√5
مثال 3: 2√50 − 3√8 = 2·5√2 − 3·2√2 = 10√2 − 6√2 = 4√2
مثال 4: √75 − √12 + √27 = 5√3 − 2√3 + 3√3 = 6√3
مثال 5 (غير متشابهة): √3 + √5 لا يمكن تبسيطها أكثر.
⚠️ أخطاء شائعة: (1) √12 + √27 = √39 خطأ؛ الجواب 5√3. (2) تجمع الجذور المختلفة (2√3 + 3√5 = 5√8 خطأ). (3) تنسى تبسيط الجذور قبل الجمع. (4) تضرب العدد الخارجي في الداخلي أثناء الجمع.
🎯 ركن الامتحان (Q13): «بسّط التعبير». الخطوات: بسّط كل جذر ← جمّع المتشابه ← اجمع المعاملات. اكتب خطوة التبسيط الوسيطة (مثل 2√3 + 3√3) لتضمن درجات الطريقة.

ملخص سريع

  • بسّط كل جذر أولًا.
  • اجمع المعاملات للجذور المتشابهة فقط.
  • لا تجمع ما تحت الجذر.
  • √a + √b ≠ √(a + b).

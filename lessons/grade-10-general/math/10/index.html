تحليل وحل x² + bx + c

🧮 الرياضيات🎓 الصف العاشر عام📌 هيكل الامتحان: Q5 · Q20

🎯 ذاكر الدرس وحل الكويز مجانًا في مذاكرتي

ندوّر على عددين: حاصل ضربهما = c و مجموعهما = b.

x² − 2x − 15: عددين ضربهم −15 وجمعهم −2 ← −5 , 3
= (x − 5)(x + 3)
حل x² + x − 20 = 0 ← (x + 5)(x − 4) = 0 ← x = −5 أو x = 4

الفكرة بالتفصيل

نريد تحليل ثلاثية الحدود x² + bx + c إلى (x + m)(x + n). نضرب القوسين: x² + (m + n)x + mn. فبالمقارنة: m + n = b وm · n = c. إذن ندوّر على عددين حاصل ضربهما c ومجموعهما b.

كيف تصطاد العددين بسرعة؟

  • إذا c موجب: العددان لهما نفس الإشارة، وهي إشارة b.
  • إذا c سالب: العددان إشارتاهما مختلفتان، والأكبر (بالقيمة المطلقة) له إشارة b.

اكتب أزواج عوامل |c| وانظر أيها يعطي مجموع b.

أمثلة محلولة

مثال 1: x² + 9x + 20: عوامل 20: (1,20) (2,10) (4,5). المجموع 9 ← 4 و5.
= (x + 4)(x + 5)
مثال 2: x² − 3x − 28: الضرب −28 والجمع −3. أزواج: (4,7)، الأكبر سالب ← −7 و4: −7 + 4 = −3 ✓.
= (x − 7)(x + 4)
مثال 3 (حل): x² − 8x + 15 = 0 ← عددان ضربهما 15 وجمعهما −8: −3 , −5. ← (x − 3)(x − 5) = 0 ← x = 3 أو x = 5.
مثال 4 (المعادلة ليست = 0): x² + 5x = 14 ← x² + 5x − 14 = 0 ← عددان ضربهما −14 وجمعهما 5: 7 , −2 ← (x + 7)(x − 2) = 0 ← x = −7 أو x = 2.
⚠️ أخطاء شائعة: (1) تعكس الإشارة في الحل: القوس (x + 7) يعطي x = −7. (2) تحلّ المعادلة وهي ليست = 0. (3) تنسى إخراج العامل المشترك أولًا (مثل 2x² + 10x + 12). (4) تتحقق من الضرب فقط ولا تتحقق من الجمع.
🎯 ركن الامتحان (Q5 · Q20): Q5 تحليل (اختيار من متعدد)، وQ20 حل معادلة. تحقق بـ FOIL من اختيارك. في الحل اكتب خطوة التحليل ثم المعادلتين ثم الحلين، فكل خطوة لها درجة.

ملخص سريع

  • ابحث عن عددين: ضربهما c وجمعهما b.
  • x² + bx + c = (x + m)(x + n).
  • المعادلة: = 0 أولًا ثم الضرب الصفري.
  • الحل عكس إشارة الرقم في القوس.
